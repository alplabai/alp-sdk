Detailed Description

STMicroelectronics LSM6DSO 6-axis IMU driver.

Verification status: [UNTESTED] – driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.

Public surface consumed by alp-studio block blk_imu_lsm6dso. Symbols carry the chip's natural prefix lsm6dso_* — no alp_ (chip drivers are bindings to third-party silicon).

I2C-only in v0.1. SPI lands in v0.2 along with lsm6dso_init_spi.

Datasheet: STMicroelectronics LSM6DSO (DocID032086).

◆ lsm6dso_init()

alp_status_t lsm6dso_init ( lsm6dso_t *  dev,
alp_i2c_t *  bus,
uint8_t  i2c_addr 
)

Bind a driver context to an open I2C bus.

Reads WHO_AM_I and verifies it matches LSM6DSO_WHO_AM_I_VAL. Does not touch ODR or full-scale registers — the caller selects those next via lsm6dso_set_accel and lsm6dso_set_gyro.

Returns
ALP_OK on success, or an error from the underlying I2C transfer. Returns ALP_ERR_IO when the WHO_AM_I check fails (chip not present or not LSM6DSO).
