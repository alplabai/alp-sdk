Detailed Description

TLS parameters for an mqtts:// broker connection.

All fields are optional. A NULL tls pointer on alp_mqtt_config_t is equivalent to tls = &(alp_mqtt_tls_config_t){0} – the backend uses the host OS's default CA path (/etc/ssl/certs on Debian/Ubuntu/Yocto images) and no client certificate. Production deployments should pin ca_file to a known-good CA bundle.
