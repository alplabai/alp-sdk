Detailed Description

OmniVision OV9281 1 MP global-shutter mono MIPI CSI-2 sensor.

Global-shutter monochrome 1280 × 800 sensor used for AR/VR tracking, ALPR, and high-speed industrial inspection. SCCB config side only; pixel data flows over MIPI CSI-2 to the SoC camera receiver behind <alp/camera.h>.

ABI status: [ABI-EXPERIMENTAL]

no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.
Driver status: [stub-impl] — chip-ID + soft reset only.
