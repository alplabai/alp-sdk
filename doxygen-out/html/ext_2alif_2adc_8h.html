Detailed Description

Alif Ensemble ADC vendor-specific knobs.

Non-portable. Include only when you've committed to Alif silicon for the gated feature. Every function in this header verifies the handle's backend is Alif before touching hardware; calls on a non-Alif handle return ALP_ERR_NOT_PRESENT_ON_THIS_SOC.

Supported silicon: alif:ensemble:e7
(e3 / e5 land in a follow-up. e8 silicon-verified in v0.8.0: 15/17 aen-* apps PASS on real E8.)

Copyright 2026 Alp Lab AB SPDX-License-Identifier: Apache-2.0

ABI status: [ABI-EXPERIMENTAL]
First vendor-extension header. Promotes to [ABI-STABLE] when three vendor families ship extensions.
