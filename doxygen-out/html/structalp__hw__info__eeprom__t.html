Detailed Description

On-EEPROM manifest layout (128 bytes total at offset 0x0000).

Programmed at production-test time by scripts/program_eeprom.py. All strings are null-terminated. Reserved bytes are zero on first programming and stay zero until a future schema_version uses them. The CRC32 (ISO-3309, polynomial 0xEDB88320 – the same zlib.crc32 Python uses) covers every byte from magic through the final byte of reserved[], exclusive of the CRC field itself.

The struct must be packed (no padding) and exactly 128 bytes; the static_assert at the bottom of this header enforces both.
