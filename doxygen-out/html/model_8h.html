Detailed Description

Read-side parser for the .alpmodel package (header + CBOR manifest).

Parses an in-memory .alpmodel into a bounded, stack-friendly view: the model identity, its per-backend target table, and blob slices. No malloc; the manifest is decoded once into a caller-provided alp_model_t.

ABI status: [ABI-EXPERIMENTAL]
