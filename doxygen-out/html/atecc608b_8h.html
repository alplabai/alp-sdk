Detailed Description

Microchip ATECC608B secure element (I²C).

EC P-256 + AES-128 hardware crypto + secure key storage in a 1-mm² SOT-23. Speaks Microchip's proprietary "ATCA" packet protocol over I²C. This driver covers chip probe + the wake / idle / sleep lifecycle commands. Crypto-engine sub-commands (sign / verify / nonce / random) land alongside the Microchip CryptoAuthLib import.
