Detailed Description

Sony IMX477 12.3 MP MIPI CSI-2 sensor (Raspberry Pi HQ Camera).

1/2.3-inch 4056 × 3040 Bayer sensor used in the RPi HQ Camera module. SCCB config side only; pixel data flows over MIPI CSI-2.
