Detailed Description

Renesas RZ/V2N N44 camera ISP vendor-specific surface.

Non-portable. Include only when you've committed to Renesas V2N silicon for the gated feature. Every function in this header verifies the handle's backend is Renesas before touching hardware; calls on a non-Renesas handle return ALP_ERR_NOT_PRESENT_ON_THIS_SOC.

Covers finer-grained ISP knobs the portable alp_camera_isp_config_t struct can't carry without leaking V2N-specific values into the public surface (3A window rectangles, per-channel gain tables, lens-shading- correction LUTs). The coarse on/off toggles for AE / AWB / AF / LSC stay in the portable struct – this header layers the per-block tuning that customers running V2N silicon for machine-vision flows reach for.

Earns its spot per the vendor-ext audit rule (spec §3a): the portable alp_camera_isp_config_t struct can't carry pixel-coordinate rectangles or kibibyte-scale LUT pointers without forcing every backend to allocate equivalent fields, which would distort the portable struct shape for SoCs without an ISP block.

Supported silicon: renesas:rzv2n:n44

Place a 3A statistics window inside the active frame.

Supported silicon: renesas:rzv2n:n44

Lets callers move the AE / AWB / AF metering rectangle off the default centre-weighted position for spot-meter style flows. Safe to call before or after alp_camera_start; the backend latches the rectangle and applies on the next frame boundary.

Bypasses alp_camera_configure_isp on purpose – the portable struct carries no rectangle fields and growing it to include them would distort SoCs without an ISP block.

Parameters
cameraHandle from alp_camera_open opened against Renesas V2N silicon. Non-NULL.
regionWhich 3A loop the rectangle targets.
rectPixel-coordinate rectangle. Non-NULL; rejects w == 0 or h == 0 with ALP_ERR_INVAL.
Returns
ALP_OK on success; ALP_ERR_INVAL on NULL handle / NULL rect / zero-sized rect / unknown region enum; ALP_ERR_NOT_PRESENT_ON_THIS_SOC on non-Renesas backend; ALP_ERR_NOT_READY if the camera isn't open.

Load a per-channel gain LUT into the N44 ISP.

Supported silicon: renesas:rzv2n:n44

Each entry is a Q4.12 gain value (1.0 == 4096) applied to the matching colour channel before AWB integration. The table is referenced – not copied – so the caller must keep the buffer alive until either the camera handle closes or a subsequent load supersedes it. This avoids a hot-path copy for the typical 256 / 512 / 1024-entry curves customers ship.

Parameters
cameraHandle from alp_camera_open opened against Renesas V2N silicon. Non-NULL.
channelWhich colour channel the curve applies to.
tablePointer to a contiguous uint16_t array. Non-NULL.
lenNumber of entries; 16..1024 inclusive. The N44 ISP rejects lengths outside this range (datasheet r01uh1003ej §18.5).
Returns
ALP_OK on success; ALP_ERR_INVAL on NULL / out-of-range arguments; ALP_ERR_NOT_PRESENT_ON_THIS_SOC on non-Renesas backend; ALP_ERR_NOT_READY if the camera isn't open.

Load the lens-shading-correction LUT.

Supported silicon: renesas:rzv2n:n44

The N44 ISP applies a 2D vignetting-correction surface stored as a flattened uint16_t grid; each entry is a Q4.12 gain applied to the matching grid cell. Grid dimensions are implementation-defined – callers pass the total cell count via len. As with the gain table the buffer is referenced (not copied); keep it alive until close.

Parameters
cameraHandle from alp_camera_open opened against Renesas V2N silicon. Non-NULL.
lutPointer to the flattened LUT. Non-NULL.
lenTotal number of grid cells; 64..4096 inclusive.
Returns
ALP_OK / ALP_ERR_INVAL / ALP_ERR_NOT_PRESENT_ON_THIS_SOC / ALP_ERR_NOT_READY.
