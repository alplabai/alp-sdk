Detailed Description

Everest Semi ES8388 stereo audio codec (I²C config + I²S data).

China-domestic cost-sensitive stereo codec (dominant on ESP32 audio boards). Same shape as wm8960 – I²C control surface here; audio sample path via <alp/i2s.h>.
