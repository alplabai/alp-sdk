Detailed Description

TI TLV320AIC3204 premium stereo audio codec (I²C + I²S).

Premium TI stereo codec with on-chip miniDSP. This driver covers the I²C control surface only – register R/W + page selection. Audio sample flow over I²S is delegated to <alp/i2s.h>.

ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes
NULL-arg smokes; no HiL silicon bring-up yet. Treat all numbers
