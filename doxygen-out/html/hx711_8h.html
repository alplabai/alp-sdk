Detailed Description

Avia Semi HX711 24-bit ADC for load cells (bit-banged 2-wire).

Classic load-cell front-end. The protocol is a custom 2-wire synchronous serial (PD_SCK clock + DOUT data), bit-banged from host GPIOs — NOT real SPI. This driver wraps the bit-banged read using the portable <alp/gpio.h> surface.

ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.
Driver status: [complete-impl] — init + bit-banged read +
gain selection + ready-wait. The ready-wait is timing-based at v0.5 (no IRQ wake); an IRQ path is a v0.6 follow-up.

Datasheet: Avia Semi HX711 v2.1 (Apr 2017).
