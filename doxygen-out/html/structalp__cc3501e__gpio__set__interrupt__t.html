Detailed Description

Payload of CMD_GPIO_SET_INTERRUPT.

Enable / disable an edge-triggered interrupt on a CC3501E GPIO and dictate which edge polarity fires the event. After setup, the firmware emits an async ALP_CC3501E_EVT_GPIO_INTERRUPT frame on each matching edge until the host disables (edge = NONE). Field-level meanings:

  • cc3501e_gpio: CC3501E pad index.
  • edge: one of alp_cc3501e_gpio_edge_t.
  • enabled: 0 = disable; 1 = enable.
