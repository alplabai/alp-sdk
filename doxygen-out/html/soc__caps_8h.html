Detailed Description

Per-SoC peripheral capability macros (auto-generated).

Auto-generated from metadata/socs/{vendor}/{family}/{part}.json by scripts/gen_soc_caps.py. DO NOT EDIT BY HAND — regenerate.

Each SoC's capability macros are gated by CONFIG_ALP_SOC_{TOKEN}. Apps select the active SoC via Kconfig. When no SoC is selected the macros default to a permissive UINT16_MAX so capability checks accept any config — apps that want runtime validation must select a specific SoC.

v0.1 generated; capability constants. See docs/abi-markers.md for the convention.
