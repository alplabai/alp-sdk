Detailed Description

TI DRV8825 bipolar stepper motor driver.

Step/dir-driven bipolar stepper board-board control surface. The driver orchestrates STEP (PWM) + DIR (GPIO) + nENBL (GPIO)

  • the three microstep-select pins M0/M1/M2 (GPIO). No on-chip register file.
ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.

Datasheet: TI DRV8825 SLVSA73F (Aug 2014).
