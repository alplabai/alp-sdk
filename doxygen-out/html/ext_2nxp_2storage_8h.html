Detailed Description

NXP FlexSPI OTFAD vendor-specific surface.

Non-portable. Include only when you've committed to NXP silicon for the gated feature. Every function in this header verifies the handle's backend is NXP before touching hardware; calls on a non-NXP handle return ALP_ERR_NOT_PRESENT_ON_THIS_SOC.

Covers the On-The-Fly AES Decryption (OTFAD) block that the i.MX 93 and RT11xx FlexSPI controllers expose. Up to four independent address windows can be live concurrently, each bound to its own key + counter; pick a window via the window_id argument.

Supported silicon: nxp:imx9:imx93, nxp:rt11xx:rt1170
(Other FlexSPI-OTFAD parts – RT10xx, RT106x, RT117x – may be added in a follow-up release once tested.)

ABI status: [ABI-EXPERIMENTAL]
Header lands ahead of the vendor pack body; every function returns ALP_ERR_NOSUPPORT until MCUXpresso FlexSPI integration lands. Promotes to [ABI-STABLE] when three vendor families ship extensions.

Provision an OTFAD key + counter for a FlexSPI address window.

Supported silicon: nxp:imx9:imx93, nxp:rt11xx:rt1170

Binds the supplied key + counter / IV into a hardware OTFAD window slot. After the call returns the host RAM no longer holds the key. alp_nxp_storage_otfad_set_window then defines the address range the slot decrypts.

Parameters
[in]sStorage handle from alp_storage_open opened against NXP silicon.
[in]window_idSlot index; must be < ALP_NXP_STORAGE_OTFAD_WINDOW_COUNT.
[in]keyKey bytes. Must be non-NULL and 16 bytes (OTFAD is AES-128-CTR fixed).
[in]counterInitial counter / IV bytes. Must be non-NULL and 16 bytes.
Returns
ALP_OK / ALP_ERR_NOT_PRESENT_ON_THIS_SOC / ALP_ERR_INVAL (bad window_id or NULL key / counter) / ALP_ERR_NOSUPPORT until the vendor pack body lands / ALP_ERR_IO on hardware bus / slot-program fault.

Define the FlexSPI address window that an OTFAD slot decrypts.

Supported silicon: nxp:imx9:imx93, nxp:rt11xx:rt1170

Address bounds are byte offsets from the FlexSPI base; both MUST be 1 KiB-aligned (OTFAD's hardware granularity). Misaligned bounds reject with ALP_ERR_INVAL rather than silently rounding.

Parameters
[in]sStorage handle from alp_storage_open opened against NXP silicon.
[in]window_idSlot index; must be < ALP_NXP_STORAGE_OTFAD_WINDOW_COUNT.
[in]start_addrWindow start address; 1 KiB-aligned.
[in]end_addrWindow end address (inclusive); 1 KiB-aligned. end_addr MUST be > start_addr.
Returns
ALP_OK / ALP_ERR_NOT_PRESENT_ON_THIS_SOC / ALP_ERR_INVAL (bad window_id, misaligned bounds, end <= start) / ALP_ERR_NOSUPPORT until the vendor pack body lands.
