Detailed Description

ADI (Maxim) MAX31855 K-type thermocouple-to-digital converter (SPI).

Read-only 14-bit thermocouple ADC with cold-junction compensation. Reports a single 32-bit packed word per read containing thermocouple temperature + internal reference temperature + fault flags (OC / SCG / SCV).

ABI status: [ABI-EXPERIMENTAL]
