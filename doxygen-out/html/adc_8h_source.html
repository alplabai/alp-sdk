324/* ================================================================== */
325/* Streaming ADC with DSP pipeline (wave-2) */
326/* */
327/* alp_adc_filter_t composes a streaming ADC source with a */
328/* filter-terminated DSP chain (FIR / IIR, optionally cascaded) so */
329/* the application receives FILTERED int16 mV samples without writing */
330/* the DSP plumbing itself. The FFT-terminated sibling */
331/* alp_adc_spectrum_t lands in the v0.5.x (c) sub-commit alongside the */
332/* spectrum-side of the wave-2 pipeline. */
333/* */
334/* On SoMs with a HW DSP block on the bridge (V2N family today; AEN */
335/* via the wave-2 GD32-side wire-format extension landing v0.5.x), the */
336/* chain runs on the bridge so raw samples never traverse the wire. */
337/* Today (v0.5.0): the host runs the chain over the existing */
338/* alp_adc_stream_t source. SoMs without a streaming ADC backend at */
339/* all return NULL with last-error = ALP_ERR_NOSUPPORT, same as */
340/* @ref alp_adc_stream_open. */
341/* ================================================================== */
