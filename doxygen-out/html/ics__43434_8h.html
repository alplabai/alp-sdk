Detailed Description

InvenSense ICS-43434 omnidirectional MEMS microphone (I²S).

Digital MEMS microphone with on-chip ΔΣ ADC. No configuration register file – channel-select (L/R) and clock polarity are set via the L/R-SEL pin and the host's I²S controller. This driver binds the per-channel selection only; sample capture flows through the portable <alp/i2s.h> peripheral surface.
