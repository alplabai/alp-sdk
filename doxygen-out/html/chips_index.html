include/alp/chips/ — public chip-driver headers

One header per supported chip. These are the headers that alp-studio's block init templates #include:

#include <alp/chips/lsm6dso.h>
static lsm6dso_t imu;
static int imu_init(void) { return lsm6dso_init(&imu, ...); }

Naming

Header path keeps the alp/ prefix (it's an SDK-shipped header), but the symbols inside use the chip's natural name — lsm6dso_t, lsm6dso_init(). No alp_lsm6dso_*. See `chips/README.md`.

See blocks/README.md at the repo root for the block-helper roster.
