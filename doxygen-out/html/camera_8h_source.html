195/* ================================================================== */
196/* ISP (Image Signal Processor) configuration */
197/* */
198/* AEN-family E4 / E6 / E8 ship a dedicated ISP */
199/* (Alif's hardened VeriSilicon ISP Pico (vsi,isp-pico) path) that */
200/* Zephyr's portable */
201/* drivers/video/ class doesn't expose at the on-chip-ISP level -- */
202/* the existing class covers sensor bridges + format negotiation but */
203/* not in-line image processing. Customers migrating from V2N to */
204/* AEN otherwise silently lose ISP acceleration. */
205/* */
206/* The minimal v0.5 surface declared below covers the headline ISP */
207/* primitives most cameras want enabled by default; finer-grained */
208/* tuning (per-channel gain tables, lens-shading-correction LUTs, */
209/* white-balance setpoints) can be added in follow-up commits as */
210/* customer demand surfaces. */
211/* ================================================================== */
