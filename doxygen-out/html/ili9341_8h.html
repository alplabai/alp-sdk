Detailed Description

Ilitek ILI9341 240 × 320 TFT driver (SPI).

Most-common embedded TFT controller. 4-wire SPI plus D/C# command/ data select. Same shape as st7789 — different init sequence.

ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.
Driver status: [partial-impl] — init + set-window + write-pixels.

Datasheet: Ilitek ILI9341 v1.11 (Jun 2011).
