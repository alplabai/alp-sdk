Detailed Description

STMicroelectronics LIS2DW12 3-axis ultra-low-power accelerometer.

Verification status: [UNTESTED] – driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.

Public surface consumed by alp-studio block blk_accel_lis2dw12. Symbols carry the chip's natural prefix lis2dw12_* — no alp_.

v0.2 scope: I2C only, ODR + full-scale + power-mode configuration, raw 14-bit accel reads. SPI lands in v0.3 alongside FIFO support.

Datasheet: STMicroelectronics LIS2DW12 (DocID030334, rev 4, Mar 2018).

Bind a driver context to an open I2C bus.

Reads WHO_AM_I and verifies it matches LIS2DW12_WHO_AM_I_VAL. Does not start sampling — caller selects ODR + full-scale + mode via lis2dw12_set_accel.

Returns
ALP_OK on success; ALP_ERR_IO on WHO_AM_I mismatch.
