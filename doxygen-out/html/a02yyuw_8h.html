Detailed Description

DFRobot SEN0312 / A02YYUW waterproof ultrasonic ranger (UART).

Cost-optimised IP67 ultrasonic distance sensor. Streams one 4-byte distance frame per ~100 ms over UART (TTL 9600/8N1):

[0xFF][HI][LO][CHK] where distance_mm = (HI << 8) | LO, CHK = (0xFF + HI + LO) & 0xFF.

ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.
