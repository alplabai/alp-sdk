Detailed Description

Surface descriptor.

Lives in caller memory; copied internally per operation so the caller can reuse the struct or modify it between calls. Field-level meanings:

  • base: pointer to the top-left pixel (no header byte).
  • width / height: dimensions in pixels.
  • stride_bytes: bytes from one row's start to the next (= width * bytes-per-pixel for tightly-packed surfaces).
  • format: one of alp_gpu2d_format_t.
