Detailed Description

Alif Ensemble OSPI SecAES vendor-specific surface.

Non-portable. Include only when you've committed to Alif silicon for the gated feature. Every function in this header verifies the handle's backend is Alif before touching hardware; calls on a non-Alif handle return ALP_ERR_NOT_PRESENT_ON_THIS_SOC.

Covers the SecAES block that the Ensemble E4 / E6 / E8 OSPI controllers expose. Key provisioning binds an AES key to a hardware slot so the key material never traces back to RAM after the call returns. Status read-back lets callers verify the engine engaged before relying on encrypted XIP.

Supported silicon: alif:ensemble:e4, alif:ensemble:e6, alif:ensemble:e8
(E3 / E5 / E7 do not expose the SecAES fabric; vendor packs may extend this list in a follow-up release.)

ABI status: [ABI-EXPERIMENTAL]
Header lands ahead of the vendor pack body; every function returns ALP_ERR_NOSUPPORT until Alif HAL integration lands. Promotes to [ABI-STABLE] when three vendor families ship extensions.

Read the SecAES engine status flags.

Supported silicon: alif:ensemble:e4, alif:ensemble:e6, alif:ensemble:e8

Lets callers verify the engine engaged before relying on encrypted XIP execution – useful in secure-boot flows where the application must abort if the encryption fabric is not confirmed live.

Parameters

Provision an inline-AES key for the OSPI SecAES engine.

Supported silicon: alif:ensemble:e4, alif:ensemble:e6, alif:ensemble:e8

Binds the supplied key into a hardware slot. After the call returns the host RAM no longer holds the key – callers may (and should) zeroise the source buffer. The cipher mode + IV / tweak passed via alp_storage_configure_inline_aes are honoured by the same hardware slot.

Parameters
[in]sStorage handle from alp_storage_open opened against Alif silicon.
[in]keyKey bytes. Must be non-NULL.
[in]key_bytes16, 24, or 32 – selects AES-128 / 192 / 256.
Returns
ALP_OK on success. ALP_ERR_NOT_PRESENT_ON_THIS_SOC if s was opened on non-Alif silicon. ALP_ERR_INVAL on NULL key or wrong key_bytes. ALP_ERR_NOSUPPORT until the vendor pack body lands. ALP_ERR_IO on hardware bus / key-load fault.
