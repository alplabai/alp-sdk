Detailed Description

Alif Ensemble VeriSilicon ISP Pico (vsi,isp-pico) vendor-specific surface.

Non-portable. Include only when you've committed to the Alif Ensemble E8 / E1M-AEN801 ISP-Pico backend currently registered in alp-sdk. Every function in this header verifies the handle's backend is Alif before touching hardware; calls on a non-Alif handle return ALP_ERR_NOT_PRESENT_ON_THIS_SOC.

Covers the finer-grained ISP knobs the ISP Pico exposes beyond the portable alp_camera_isp_config_t struct:

  • 3A statistics windows (ISP Pico carries 1024 weighted metering cells per loop; the API surface picks a coarser rectangle to match the Renesas V2N N44 ISP's surface).
  • per-channel gain LUTs.
  • lens-shading-correction LUT (the ISP Pico's "MESH" mode).

Earns its spot per the vendor-ext audit rule (spec §3a): the portable alp_camera_isp_config_t struct can't carry pixel-coordinate rectangles or kibibyte-scale LUT pointers without forcing every backend (including AEN-family E3 / E5 / E7 silicon without the ISP Pico fabric) to allocate equivalent fields. Same shape as <alp/ext/renesas/camera.h> – callers targeting both V2N and AEN silicon get a near-identical API surface; the vendor-handle gate keeps each call routed to the matching hardware.

Supported silicon: alif:ensemble:e8 (E1M-AEN801)
E4 / E6 ISP-Pico support needs explicit backend registrations and board validation before this contract is widened.

ABI status: [ABI-EXPERIMENTAL]
Every function returns ALP_ERR_NOSUPPORT today, but not for one reason: AE is declared in the vendored isp_wrapper headers but undefined in its archive; AF and LSC are absent from that archive outright (no header, no symbol); AWB is reachable in the archive but deliberately withheld so AE/AF can't silently stay unset while AWB moves alone. The gain-table load fails for an additional, independent reason – a symbol exists but its struct can't carry this call's contract – see the per-entry detail in src/backends/ext/alif/camera.c. Promotes to [ABI-STABLE] when three vendor families ship extensions.

Place a 3A statistics window inside the active frame.

Supported silicon: alif:ensemble:e8 (E1M-AEN801)

Mirrors the Renesas knob's contract. ISP Pico weights the matching 1024-cell statistics grid by the inclusive rectangle.

Parameters
cameraHandle from alp_camera_open opened against an Alif E8 SoC.
regionWhich 3A loop the rectangle targets.
rectPixel-coordinate rectangle. Non-NULL; rejects w == 0 or h == 0 with ALP_ERR_INVAL.
Returns
ALP_OK on success; ALP_ERR_INVAL on NULL handle / NULL rect / zero-sized rect; ALP_ERR_NOT_PRESENT_ON_THIS_SOC on non-Alif backend; ALP_ERR_NOSUPPORT today for every region, but not for one shared reason: AE is declared-but-undefined in the vendored archive, AF is absent from it outright, and AWB is technically reachable (the archive defines the call) but deliberately withheld so AE/AF can't silently stay unset while AWB moves alone – see the file-header ABI-status note above.
