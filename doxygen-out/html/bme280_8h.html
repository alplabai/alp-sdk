Detailed Description

Bosch BME280 combined temperature / humidity / pressure sensor driver.

Verification status: [UNTESTED] – driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.

Public surface consumed by alp-studio block blk_env_bme280. Symbols carry the chip's natural prefix bme280_* — no alp_.

v0.2 scope: I2C only, single-shot ("forced") and continuous ("normal") sampling modes, raw register reads + compensation helper that lifts the 20/20/16-bit raw output into degrees-celsius (×100), pascals, and RH (×1024) using the chip's per-die calibration coefficients. SPI arrives in v0.3.

Datasheet: Bosch BME280 (BST-BME280-DS002 v1.6, May 2022).

alp_status_t bme280_init ( bme280_t *  dev,
alp_i2c_t *  bus,
uint8_t  i2c_addr 
)

Bind a driver context to an open I2C bus.

Reads CHIP_ID and verifies it matches BME280_CHIP_ID, then loads the per-die calibration coefficients into dev. Leaves the oversampling / mode registers untouched — call bme280_set_sampling next.

Returns
ALP_OK on success; ALP_ERR_IO on a CHIP_ID mismatch (chip absent or not a BME280).

Configure sampling parameters.
