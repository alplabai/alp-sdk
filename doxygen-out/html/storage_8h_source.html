284/* ================================================================== */
285/* Inline AES (on-the-fly XIP encryption / decryption) */
286/* */
287/* AEN-family OSPI / HexSPI controllers can transparently */
288/* encrypt + decrypt data between the host bus and the external chip */
289/* (XIP code stays AES-protected; the host sees plaintext, the flash */
290/* sees ciphertext). Customers migrating from V2N to AEN otherwise */
291/* lose the secure-XIP capability silently. */
292/* */
293/* The minimal v0.5 surface declared below covers the cipher mode + */
294/* key + IV needed to set up inline-AES on the open device. Re- */
295/* keying mid-session is supported by calling configure_inline_aes() */
296/* again; passing mode == ALP_STORAGE_AES_OFF disables it. */
297/* ================================================================== */
298
