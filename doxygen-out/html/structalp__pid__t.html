Detailed Description

PID controller state.

Caller-owned; opaque in practice.

Allocate one per control loop (static or stack), initialise with alp_pid_init, then drive with alp_pid_step. Do not read or write the fields directly – the layout is [ABI-EXPERIMENTAL].
