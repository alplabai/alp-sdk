Detailed Description

Generic button + LED block helper.

Verification status: [UNTESTED] – driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.

Consumed by alp-studio block blk_button_led. Lives under <alp/blocks/> (NOT <alp/chips/>) because this is an SDK-level block utility, not a binding to a single third-party IC. Hence the alp_ prefix on every symbol — the button could be any momentary switch and the LED any indicator; the helper just orchestrates the GPIO pair. See blocks/README.md for the full block-vs-chip rationale.

Wraps <alp/peripheral.h> GPIO calls; portable across all three OS targets.
