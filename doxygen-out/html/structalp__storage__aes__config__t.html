Detailed Description

Inline-AES configuration.

Caller-owned memory; backend reads the key / IV at configure() time and may bind to a HW key slot (the HW key never traces back to RAM after that point). Field-level meanings:

  • mode: one of alp_storage_aes_mode_t.
  • key: pointer to the key bytes (length per key_bytes).
  • key_bytes: 16, 24, or 32 – selects AES-128 / 192 / 256.
  • iv: pointer to the IV / tweak bytes (length per iv_bytes). 16 bytes for both CTR + XTS in the standard modes.
  • iv_bytes: typically 16.
