188/* ------------------------------------------------------------------ */
189/* Operating-point profiles */
190/* */
191/* Some SoCs keep the power/clock tree behind a system-controller */
192/* firmware: the application core never pokes PLL / DC-DC / power- */
193/* domain registers directly, it reads and writes a per-core PROFILE */
194/* instead. This handle-less surface exposes the two profiles every */
195/* such platform keeps -- the active RUN operating point and the */
196/* STANDBY (off/retention) operating point -- through portable fields. */
197/* ------------------------------------------------------------------ */
