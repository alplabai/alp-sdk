Detailed Description

A single CAN frame (TX or RX).

payload_len is a decoded byte count, not a wire CAN/CAN-FD DLC (Data Length Code) nibble. A real CAN-FD DLC is a 4-bit encoded value (0..15) that maps non-linearly onto 0..64 bytes above 8; that mapping is a backend-internal concern (see e.g. Zephyr's can_dlc_to_bytes() / can_bytes_to_dlc()) and never appears in this portable struct.
