Detailed Description

Quectel BG95 LTE-M / NB-IoT cellular module (UART AT).

Multi-mode (LTE Cat M1 + Cat NB2 + EGPRS) cellular module controlled over UART using the standard 3GPP AT command set. This driver covers the line-layer AT-command shell only: init + send_cmd + read_response + deinit. The TCP / MQTT / FTP / HTTP profiles built on top of AT are app-level code, layered on this driver's AT-command shell.
