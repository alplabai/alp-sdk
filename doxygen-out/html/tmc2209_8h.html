Detailed Description

Trinamic TMC2209 silent stepper driver (UART-controlled).

Step/dir + UART-tunable bipolar stepper driver dominant in the desktop-3D-printer ecosystem. This driver covers the UART register-access surface; step/dir pacing reuses the <alp/pwm.h> portable layer the way drv8825 already does.

ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.
Driver status: [stub-impl] — UART CRC + register-read /
register-write helpers. GCONF / IHOLD_IRUN / CHOPCONF setters land in follow-up commits.

Datasheet: Trinamic TMC2209 v1.09 (Aug 2020).
