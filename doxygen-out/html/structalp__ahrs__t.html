Detailed Description

AHRS filter state.

Caller-owned; opaque in practice.

The orientation is held as a unit quaternion (q0, q1, q2, q3) mapping the sensor frame to the earth frame. Do not read or write the fields directly – the layout is [ABI-EXPERIMENTAL]; use alp_ahrs_euler.
