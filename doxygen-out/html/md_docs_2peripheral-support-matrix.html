Peripheral Support Matrix

One row per E1M SoM SKU, one column per peripheral class. A cell is ✅ when the module's on-module silicon declares at least one instance of that class, — when it does not.

This table is auto-generated from the single-source hardware metadata: each SoM preset (metadata/e1m_modules/E1M-*.yaml) names its silicon via a silicon: ref, which resolves to a SoC spec (metadata/socs/<vendor>/<family>/<part>.json). The SoC's peripherals: counts and npus: array are the zero-drift source of truth – edit the metadata, not this file.

Scope: presence only. Driver maturity (tier, GA / stub) is not structured metadata and is tracked separately in os-support-matrix.md; it is intentionally out of scope here.

‍A blank (—) means the class is not declared in the SoC metadata. Where a SoC's peripheral counts have not yet been fully ingested the row is sparse; cells fill in automatically once the metadata lands (the CI drift gate keeps this file in sync).
