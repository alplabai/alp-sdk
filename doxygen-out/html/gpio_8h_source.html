104/* ------------------------------------------------------------------ */
105/* Portable GPIO proxy wiring (CONFIG_ALP_SDK_GPIO_CC3501E_PROXY). */
106/* */
107/* When the proxy backend is built, alp_gpio_open(pin_id) on the AEN */
108/* target routes pin_ids listed in cc3501e_gpio_routes[] through the */
109/* bridge (cc3501e_gpio_*); every other pin_id delegates to the */
110/* platform GPIO driver. The board provides the route table (filled */
111/* from the SoM pad map); the SDK ships a WEAK empty default so an */
112/* un-mapped build delegates every pin (no behaviour change). The app */
113/* calls alp_gpio_cc3501e_attach() once after cc3501e_init() so the */
114/* proxy has a bridge handle; until then proxied pins delegate too. */
115/* ------------------------------------------------------------------ */
