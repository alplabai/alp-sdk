◆ ready_pin

alp_gpio_t* cc3501e::ready_pin

OPTIONAL host-IRQ/READY in (CC35 GPIO17 -> Alif P2_6): HIGH when the SPI slave is armed+idle.

When populated, cc3501e_request() waits on it before each reply phase instead of a fixed settle gap. NULL = legacy fixed gap.
