void* alp_inference_config_t::arena

Caller-allocated arena, or NULL to let the backend use its built-in default.

A model that dispatches onto the Ethos-U NPU (it carries the fused Ethos-U op – typically a Vela-compiled model, whatever format reports) has NO safe default: the NPU is a DMA master whose accesses are pinned to the SRAM AXI port, so the arena MUST be an explicit NPU-reachable (SRAM0-resident) buffer sized to the model. arena = NULL for such a model is rejected with ALP_ERR_INVAL (see examples/aen/aen-npu-inference-alp).

◆ arena_bytes

size_t alp_inference_config_t::arena_bytes

Bytes of scratch arena the backend may use.

TFLM-style backends size this from the compile-time tensor arena estimate; if 0, the backend uses a built-in default.
