Detailed Description

One-pass summary statistics over a real float buffer.

Populated by alp_dsp_stats_f32. All fields describe the buffer passed to that call verbatim – if the caller wants AC statistics (DC/mean removed), it must mean-centre the buffer first and pass the centred data.
