Detailed Description

STMicroelectronics LPS22HB pressure sensor (I²C).

24-bit pressure + temperature MEMS barometer, ±0.1 hPa absolute accuracy. Common in ST's IoT eval boards alongside the lis2dw12 accelerometer already shipped.

ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.

Datasheet: ST LPS22HB Rev 6 (Mar 2018).
