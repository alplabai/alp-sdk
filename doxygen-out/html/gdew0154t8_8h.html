Detailed Description

GoodDisplay GDEW0154T8 1.54" monochrome e-paper module (SPI).

200 × 200 monochrome e-paper module common on the M5Stack Core Ink and ESP32 e-paper boards. 4-wire SPI plus D/C# / RESET / BUSY ancillaries. Same overall shape as il3820 — different panel geometry and refresh waveform.

ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.
Driver status: [stub-impl] — init + busy-wait + soft reset.

Reference: GoodDisplay GDEW0154T8 module datasheet (Rev 1.0).
