Detailed Description

Options for loading a .alpmodel package (the fat multi-backend container).

Provide the bytes in-memory (data/size, MCU embed) or a storage path (Linux). backend = AUTO lets the loader pick the best blob for the active SoM; pin a specific backend to force it.
