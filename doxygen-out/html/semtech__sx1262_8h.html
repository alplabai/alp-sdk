Detailed Description

Semtech SX1262 LoRa transceiver (SPI).

Sub-GHz LoRa/FSK transceiver – the newer SX126x family that supersedes SX1276 in new designs. Driver covers register read / write + a GetStatus probe; LoRa packet TX/RX layer lives in the (LoRaWAN MAC-layer) LoRaMac-node library.

ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.
Driver status: [stub-impl] — SPI shell + status probe.

Datasheet: Semtech SX1262 v1.2 (Jun 2019).
