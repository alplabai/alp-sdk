Detailed Description

Alp SDK real-time-clock abstraction.

Wraps the SoC's wall-clock RTC. Time is exchanged in a struct shaped after struct tm so apps can format-print without an extra conversion step.

Backends:

  • Zephyr : rtc_* driver class (Zephyr 3.5+).
  • Yocto : clock_gettime(CLOCK_REALTIME) + /dev/rtc0.
  • Baremetal: vendor HAL RTC peripheral.

Typical usage:

alp_rtc_t *rtc = alp_rtc_open(0);
alp_rtc_time_t t = {
.year = 2026, .month = 5, .day = 10,
.hour = 14, .minute = 30, .second = 0,
};
alp_rtc_set_time(rtc, &t);

◆ alp_rtc_open()

alp_rtc_t * alp_rtc_open ( uint32_t  rtc_id)

Acquire an RTC handle.

Most SoMs expose exactly one RTC; pass rtc_id = 0. Multi-RTC SoMs (e.g. RZ/V2N has the SoC RTC + a battery-backed PMIC RTC) map to higher ids via the alp-rtc<N> devicetree alias.

Parameters
[in]rtc_idStudio-resolved RTC index (0..1).
Returns
Open handle on success, or NULL on resolution failure.
