Detailed Description

Alp SDK I²S / SAI bus abstraction.

The audio-data bus underneath <alp/audio.h> and the PDM helper in <alp/blocks/pdm_mic.h>. Apps that want to talk directly to a DAC, a digital-mic array, or a SAI-attached codec come here.

Backends:

  • Zephyr : i2s_* driver class.
  • Yocto : ALSA hwparams over the kernel's I²S DAI.
  • Baremetal: vendor HAL SAI / I²S peripheral.

Memory model. The Zephyr backend allocates a 2-block ping-pong memory slab inside alp_i2s_open. Writes copy the caller's buffer into the slab; reads copy the slab block into the caller's buffer + free the slab block immediately. That trades two memcpys for not surfacing Zephyr's mem_slab lifecycle in the public API. Apps that need true zero-copy can drop to the underlying Zephyr i2s_* driver class directly.

ABI status: [ABI-STABLE]
v0.2. See docs/abi-markers.md for the convention.

Default-initialize an alp_i2s_config_t for bus id.

Identity from id; canonical defaults: sample_rate_hz = 48000 (the common professional/CD-audio I²S rate), word_bits = 16 and channels = 2 (16-bit stereo, the usual codec-facing shape), format = ALP_I2S_FMT_I2S ("most modern codecs accept" this per the file header), direction = ALP_I2S_DIR_RX (the passive, listen-only default – matches the enum-zero convention used by every other ALP_*_CONFIG_DEFAULT), block_frames = 256 (matching the DMA/ring block size used elsewhere in the SDK).

Note
Expands to a compound literal (a GCC/Clang extension in C++ – the SDK's toolchains; standard through C23). Usable as an initializer or an expression. On a compiler that rejects compound literals in C++ (e.g. MSVC), initialize the config's fields individually.

◆ alp_i2s_open()

alp_i2s_t * alp_i2s_open ( const alp_i2s_config_t *  cfg)

Configure an I²S bus and allocate its DMA buffer slab.

Does not start the clock — call alp_i2s_start when ready to stream. All config fields are validated against the backend; an unsupported sample rate or word width returns NULL here, not later.

Parameters
[in]cfgConfiguration. Must be non-NULL with valid channels (1 or 2), word_bits (16/24/32), and block_frames > 0.
Returns
Open handle on success, or NULL on:
  • invalid cfg
  • bus_id out of range
  • underlying device not ready
  • heap allocation failure for the slab

Pull the next PCM block from the RX path.

Returns the count actually copied via bytes_out. May be less than bytes if the driver's block size is smaller; never more.

Parameters

[out]blockDestination buffer.
[in]bytesDestination capacity.
[out]bytes_outReceives the byte count copied. May be NULL.
[in]timeout_msCaller's preferred wait budget.
