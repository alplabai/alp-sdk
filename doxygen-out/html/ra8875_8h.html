Detailed Description

RAiO RA8875 LCD controller + resistive-touch IC (SPI).

Embedded LCD controller for 5–7" panels with on-chip framebuffer, BTE 2D acceleration, and an integrated 5-wire resistive-touch controller. 4-wire SPI; D/C select packed into the SPI command byte (no separate D/C# pin like ILI9xxx).

ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.
Driver status: [stub-impl] — chip-ID probe + soft reset.
Panel-init / BTE / touch lifecycle land once the maintainer adds the RA8875 panel-init table to the design archive.

Datasheet: RAiO RA8875 v1.7 (Mar 2014).
