Detailed Description

ams TSL2591 wide-dynamic-range ambient-light sensor (I²C).

600 M:1 dynamic range visible + IR light sensor. Two 16-bit ADC channels (full-spectrum + IR-only) – visible light is the difference.

ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.

Datasheet: ams TSL2591 v0.7 (May 2013).
