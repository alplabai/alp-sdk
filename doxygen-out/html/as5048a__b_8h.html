Detailed Description

ams AS5048A / AS5048B 14-bit magnetic rotary encoder.

AS5048A speaks SPI; AS5048B speaks I²C. This driver covers the I²C variant — AS5048B at 7-bit address 0x40 (strap-selectable 0x40..0x43). SPI variant lives in a parallel as5048a_spi driver in a follow-up.

ABI status: [ABI-EXPERIMENTAL]
Verification status: [UNTESTED] — driver compiles + passes NULL-arg smokes;
no HiL silicon bring-up yet. Treat all numbers + lifecycle sequencing as paper-correct only until the v1.0 verification sweep lands.

Datasheet: ams AS5048A/B v1.7 (Nov 2018).
