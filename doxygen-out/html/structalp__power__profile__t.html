Detailed Description

One operating-point profile in portable units.

Frequencies are Hz and rails are millivolts. The domain / memory / wake bitmasks are IMPLEMENTATION-DEFINED: their bit legends are SoC business documented in the per-SoM HW reference, and portable code must treat them as opaque tokens (read-modify-write them, log them, compare them – never construct them from portable constants).

A zero field means "unknown / not reported" on alp_power_profile_get and "keep the current value" on alp_power_profile_set.
