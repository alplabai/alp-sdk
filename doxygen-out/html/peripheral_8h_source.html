458/* ------------------------------------------------------------------ */
459/* I2C -- target (slave) mode */
460/* */
461/* Makes this MCU answer on the bus as an addressable device (a */
462/* "register-mapped peripheral" from the external controller's point */
463/* of view). Byte-granular callbacks mirror the wire protocol, so a */
464/* register-file slave is a ~20-line state machine on top of them. */
465/* */
466/* Availability: requires controller-driver target support (Zephyr: */
467/* CONFIG_I2C_TARGET + a driver that implements target_register). */
468/* Drivers without it fail open() with ALP_ERR_NOSUPPORT (or */
469/* ALP_ERR_NOT_READY when the bus alias is unset) -- applications */
470/* must degrade cleanly. native_sim's emulated controller accepts */
471/* the registration but no external controller ever drives it, so */
472/* callbacks never fire there. */
473/* */
474/* ABI status: [ABI-EXPERIMENTAL] -- v0.9 new. */
475/* ------------------------------------------------------------------ */

699/* ------------------------------------------------------------------ */
700/* SPI -- target (slave) mode */
701/* */
702/* Makes this MCU the clocked side of the bus: the external */
703/* controller owns SCK + /CS and decides when (and how many) bytes */
704/* move. Because SPI is full-duplex and the target cannot see a */
705/* command before responding within the SAME transfer, the surface is */
706/* transfer-based: preload a TX response, block until the controller */
707/* clocks a transfer, inspect what arrived, preload the next reply. */
708/* */
709/* Availability: requires controller-driver slave support (patchy */
710/* across Zephyr SoC drivers; needs CONFIG_SPI_SLAVE). Backend-level */
711/* absence fails open() with ALP_ERR_NOSUPPORT / ALP_ERR_NOT_READY; */
712/* driver-level absence surfaces on the FIRST transceive as */
713/* ALP_ERR_NOSUPPORT (the Zephyr backend cannot probe it at open). */
714/* native_sim: the emulated controller accepts a slave-mode open, but */
715/* nothing external ever clocks a transfer -- degrade cleanly (and */
716/* bound your waits) either way. */
717/* */
718/* ABI status: [ABI-EXPERIMENTAL] -- v0.9 new. */
719/* ------------------------------------------------------------------ */
720

946/* ------------------------------------------------------------------ */
947/* UART -- byte-granular RX ring buffer (optional) */
948/* */
949/* Opt-in helper layered on top of an open alp_uart_t. Once attached, */
950/* the SDK's interrupt-driven RX path drains the controller FIFO into */
951/* a caller-supplied backing store on every byte; the consumer thread */
952/* pops bytes via alp_uart_rx_ringbuf_pop without polling the device. */
953/* */
954/* Availability: */
955/* - Zephyr: requires CONFIG_ALP_SDK_UART_RX_RINGBUF=y plus */
956/* CONFIG_UART_INTERRUPT_DRIVEN=y. Other backends return */
957/* NULL / ALP_ERR_NOSUPPORT today (Yocto-side termios already */
958/* buffers in-kernel; baremetal lands once UART IRQ wiring does). */
959/* */
960/* Concurrency: alp_uart_rx_ringbuf_pop / _count run from the */
961/* consumer thread only; the producer side (UART IRQ) runs inside */
962/* the SDK and uses LwRB's single-producer-single-consumer guarantees. */
963/* ------------------------------------------------------------------ */
