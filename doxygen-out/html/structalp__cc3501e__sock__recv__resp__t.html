Detailed Description

Reply DATA header for CMD_SOCK_RECV (precedes the received bytes, which follow inline with no padding).

data_len == 0 means no data was available (non-blocking semantics; the status is still ALP_CC3501E_RESP_OK). Field-level meanings:

  • from: peer endpoint for DGRAM sockets (alp_cc3501e_sock_addr_t); zeroed for STREAM sockets.
  • data_len: number of received bytes that follow inline.
