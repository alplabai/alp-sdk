Detailed Description

CC3501E camera-enable LDO host helper (opcodes 0x60/0x61).

The CC3501E fronts the two on-module camera-enable LDOs; this helper lets the host drive them over the inter-chip bridge. Synchronous + fast in the firmware (no worker, no radio bring-up), so it takes the caller's timeout with no down-window floor – but it still retries on a transient IO (the bridge is briefly down if a radio op is running concurrently).
