84/* The `used` attribute keeps the symbol through compile-time stripping;
85 * `retain` (GCC 11+) keeps it through linker `--gc-sections`. Zephyr's
86 * native_sim builds enable --gc-sections aggressively and drop the
87 * registration without `retain`. */
88/* Section name MUST be a valid C identifier (no leading dot) so GNU
89 * ld auto-emits __start_alp_backends_&lt;class&gt; and __stop_&lt;class&gt;
90 * bound symbols. `retain` keeps the entry through --gc-sections. */
