# A32 bare-metal memory probe — spec (2026-09-22)

Goal: first numbers from the Cortex-A32 (800 MHz, NEON, L1/L2) on a bench E1M-AEN803,
to compare with M55-HP (SRAM0 Helium fill 1279.95 MB/s, SRAM0 scalar copy 43.23 MB/s,
Helium copy 92.74 MB/s). Decides whether the A32 pair should rasterise the 3D game.

## Boot contract (from TF-A source, <Alif TF-A>, alif_lts-v2.10.8, PLAT=devkit_e7)

- SE releases A32_0 into TF-A sp_min (BOOTLOAD, bl32.bin, MRAM 0x80002000).
- sp_min erets to BL33 at PRELOADED_BL33_BASE = **0x80020000** (XIP from MRAM), AArch32 **SVC**,
  **Non-secure**, IRQ/FIQ/Abort **masked**, MMU/caches off (NS SCTLR unprogrammed). r0=0, r1=~0, r2=DTB — ignore.
  No image header is parsed — first word at 0x80020000 is executed.
- PSCI CPU_ON (AArch32 SMC id 0x84000003) starts core 1 (not used in stage 1).
- CNTFRQ = 100 MHz (SYS_COUNTER_FREQ_IN_TICKS). Use CNTVCT (mrrc p15, 1, r0, r1, c14).
- Console UART5 base 0x4901D000, 115200, pinmuxed by TF-A (optional; not required).
- TF-A secure MHU0 payload window 0x02380000..0x02380FFF — DO NOT touch.
- ATOC: <SETOOLS>/build/config/e1m-aen-evk-linux.json,
  entry A32_APP (cpu_id A32_0, mramAddress 0x80020000) — the payload .bin replaces xipImage.bin.

## Memory plan (SRAM0 0x02000000..0x023FFFFF, 4 MiB; all 1 MiB MMU sections)

| range | use | MMU attribute |
|---|---|---|
| 0x02000000-0x020FFFFF | test buffer NC | Normal, non-cacheable |
| 0x02100000-0x021FFFFF | test buffer WB | Normal, write-back write-allocate cacheable |
| 0x02200000-0x022FFFFF | copy destination NC | Normal, non-cacheable |
| 0x02300000-0x023FFFFF | page table @0x023E0000 (16 KiB), stack top 0x023FF000, **results @0x023FF000**; avoid 0x02380000-0x02380FFF | Normal, non-cacheable |
| 0x80000000-0x805FFFFF | MRAM (code, rodata) | Normal WB cacheable, read-only use |
| everything else | Device (strongly-ordered) | |

No .data/.bss in MRAM: all mutable state lives in the results block / stack. (If .bss is needed,
place it at 0x023F8000 and zero it in start.S.)

## Startup (start.S, ARM state, -mcpu=cortex-a32 -marm)

1. Vector table at 0x80020000 (reset = branch to start); set VBAR to it. Data/prefetch abort
   and undef handlers: write a fault code + DFAR/DFSR/IFAR/IFSR + LR into the results block, then
   jump to the SRAM park loop (below).
2. SP = 0x023FF000 (grows down; stack only below results).
3. Results header: magic 0xA32A0001, stage = 1.
4. Invalidate: I-cache (ICIALLU), branch predictor (BPIALL), TLB (TLBIALL), and data caches by
   set/way over all levels from CLIDR (DCISW) — the standard ARMv7/v8-AArch32 loop.
5. Build the section table at 0x023E0000 per the memory plan (TEX/C/B: NC = TEX=001 C=0 B=0;
   WB-WA = TEX=001 C=1 B=1; Device = TEX=000 C=0 B=1 shareable; AP=full access, domain 0, XN on
   device + SRAM sections). TTBR0 = table | (cacheable walk bits), TTBCR = 0, DACR = 0x55555555
   (client). DSB; ISB.
6. SCTLR |= M | C | I | Z (branch prediction). ISB.
7. NEON/VFP: CPACR |= (0xF << 20); ISB; FPEXC = 0x40000000 (EN). If NS access is refused
   (undef on vmsr), the undef handler records it — report, do not guess.
8. Copy the park loop (`1: wfi; b 1b`) into SRAM0 at 0x023FE000 (NC section, but it must be
   executable: map that one 1 MiB section without XN — i.e. 0x023xxxxx section is NOT XN), clean,
   and branch there at the end. The core must NOT sit executing from MRAM once tests finish, so a
   later MRAM write cannot tear under it.
9. Call main(); stage = 0xD0E when it returns; branch to the SRAM park loop.

## main.c tests (C + NEON intrinsics <arm_neon.h>, -O2, -mfpu=neon-fp-armv8 -mfloat-abi=hard)

Timing: CNTVCT ticks (100 MHz). Each test: one untimed warm pass, then N timed passes; record
ticks and bytes. Use volatile/checksums so nothing is optimised away (checksum written to results).

Per buffer X in {NC 0x02000000, WB 0x02100000}, working set 1 MiB (and 16 KiB for WB to show the
L1-resident rate):
- scalar fill (32-bit stores)
- NEON fill (vst1q_u32 x4 per iteration = 64 B)
- NEON read (vld1q_u32, xor-accumulate)
- NEON copy X -> NC dst 0x02200000
- WB only: after NEON fill, DCCMVAC clean of the 1 MiB range (+DSB): record clean ticks
  separately (this is the cost of making a cached back buffer visible to the CDC200).
Then a single-word read of SRAM1 0x02400000 LAST (stage = 0x5A1): if it data-aborts, the abort
handler records it and parks.

Results block at 0x023FF000 (little-endian, all uint32 unless noted):
```
+0x00 magic 0xA32A0001
+0x04 stage (advances before each test; 0xD0E = all done)
+0x08 fault code (0 none, 1 undef, 2 pabort, 3 dabort)
+0x0C DFSR  +0x10 DFAR  +0x14 IFSR  +0x18 IFAR  +0x1C fault LR
+0x20 CNTFRQ read back
+0x24 SCTLR read back   +0x28 CPACR read back   +0x2C FPEXC read back
+0x30 checksum
+0x34 SRAM1 word read (if it returned)
+0x40.. array of { uint32 test_id; uint32 bytes_lo; uint32 bytes_hi; uint32 ticks_lo; uint32 ticks_hi; } x up to 32
```
test_id encoding: (buffer<<8)|op, buffer 1=NC 2=WB-1MiB 3=WB-16KiB, op 1=scalar fill 2=neon fill
3=neon read 4=neon copy 5=clean.

## Build

`trace-runner/a32/probe/`: start.S, main.c, link.ld (ORIGIN 0x80020000, text+rodata only),
Makefile using `arm-none-eabi-gcc` (<toolchain bin>, 13.3.1) — `-mcpu=cortex-a32 -marm
-mfpu=neon-fp-armv8 -mfloat-abi=hard -O2 -ffreestanding -nostdlib -nostartfiles`; objcopy -O binary
to a32_probe.bin; emit a map and `size`. Host-side decoder `a32/probe/decode.py`: takes a hex/bin
dump of 0x023FF000..+0x200 and prints each test's MB/s = bytes*100e6/ticks/1e6 and the fault/
readback fields.

## Verification before any flash

- Disassemble: vector table at 0x80020000, no absolute references outside MRAM/SRAM0/devices,
  no .data/.bss load in MRAM.
- Build a host smoke of decode.py with a synthetic block.
- An alp-reviewer pass on start.S (cache/MMU sequence is the risk).
