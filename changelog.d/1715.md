### Fixed — a citation stopped being checked the moment it shipped (#1715)

`check_changelog_citations.py` enumerated only `changelog.d/*.md`, so a citation was
verified while it sat in a fragment and then **never again** once that fragment was folded
into `CHANGELOG.md` at release time — which is exactly when it starts to rot. #1498 was the
symptom; the hole that let it ship is fixed here.

`CHANGELOG.md` is now scanned too, but its two halves carry different contracts and are
graded differently:

- **`[Unreleased]`** describes the current tree, so a broken citation there is an **error**,
  same as a fragment.
- **A released section is a historical record** of a tree that no longer exists. Some of its
  citations are unfixable by construction, and rewriting them to suit today's tree would
  falsify what shipped. Those are reported as **warnings** — visible, never silently passed,
  never blocking.

Grading released history as errors would have made this gate unlandable without editing
shipped release notes, which is the opposite of what a changelog is for. Three such
citations exist on `dev` today and are now surfaced as warnings (quoted in a fenced block
below because they are dead paths by construction — writing them as live citations here
would trip this very gate, which is itself the behaviour working):

```
alp_cli/new_som.py:154   -- deleted with the alp_cli retirement (#1367/#1368)
docs/Overview.md         -- deleted
docs/abi/README.md:157   -- anchor "no final v0.15.0 tag exists yet", correctly
                            removed once v0.15.0 GA shipped
```

Eight citations that *were* genuinely fixable are corrected in the same change: three
anchor drifts re-resolved to where the code moved
(`include/alp/protocol/cc3501e.h` 447 -> 534, `cc3501e-bridge-firmware:hal/ti/cc3501e_hw_ti_wifi.c`
715 -> 781, `src/zephyr/console/alp_console_companion_wifi.c` 348 -> 416), and five bare
filenames rewritten as repo-relative paths so the resolver can find them at all. Citation
count went 74 resolved / 11 errors to 77 resolved / 0 errors + 3 warnings.
