### Changed — wdt: alp_wdt_close() never disarms the watchdog on Yocto (#2981)

**On Yocto, alp_wdt_close() no longer disarms the watchdog.** It issues neither WDIOS_DISABLECARD nor the magic close character, so the watchdog keeps running after close, matching Zephyr, provided the Linux driver advertises WDIOF_MAGICCLOSE or the kernel is built with CONFIG_WATCHDOG_NOWAYOUT (otherwise the kernel stops it on close). Code that relied on close() to stop the watchdog must now call alp_wdt_disable() first (or keep feeding it from another owner); a crash or exit after arming resets the board. wdt.h now states the single portable contract.
