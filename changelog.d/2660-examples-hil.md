### Changed — V2N audit: CM33 examples that targeted A55-owned peripherals are removed, DRP-AI gets model-free HIL probes and a reconciled compile schema (XSPI-2, XSPI-3, NPU-12, NPU-05) (#2660)

- **Removed `examples/v2n/v2n-xspi-flash-readwrite`, `v2n-emmc-block-stat`, `v2n-ethernet-dual` (XSPI-2, XSPI-3).** They drove xSPI0, SDHI0 and GBETH from the CM33, but Linux on the A55 owns all three; the xSPI example also erased offset `0x1FFF000`, inside the live `fip` partition that holds the CM33 image. No portable `<alp/flash.h>`, disk or MDIO surface exists to retarget them to the A55 Yocto backends, so they are deleted along with their portability allowlist entries, catalog rows and doc references. The A55-side checks live in `tests/hil/v2n101-x-evk/` (`v2n101-xspi-mtd`, `v2n101-emmc-block`, `v2n101-ethernet-link`).
- **HIL: model-free DRP-AI probes `v2n101-drpai-present` and `v2m103-drpai-present` (NPU-12).** Check the `drpai-rz 17000000.drpai` probe, the `drpai-rz` sysfs bind and `/dev/drpai0`. The `DRPAI_GET_DRPAI_AREA` window is not checked (needs python3, absent from ALP images). `/dev/drpai0` mode/group is not asserted (policy undecided). The inference spec gets no latency ceiling or top-1 check: the spec format only supports `expect_contains` / `expect_absent` substrings. Unverified on a unit.
- **`models[].compile.drpai` schema now matches the adapter (NPU-05).** Declares `input_shape`, `input_name`, `images` and optional `product` (`V2N` / `V2H`, case-insensitive) instead of the unused `spec`, so `tan validate` accepts what `tan model build` reads. Hermetic tests cover the schema and the CI skip when the DRP-AI TVM toolchain is absent.
