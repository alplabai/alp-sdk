### Added — CI gate: assert every ALP-Bxxx emission site has a doc page (#1569)

`scripts/check_diagnostic_narratives.py` and `scripts/gen_error_catalog.py`
both walk `docs/diagnostics/ALP-B*.md` -- neither walks the
`scripts/alp_cli/validator.py` `code="ALP-Bxxx"` emission sites, so a code
the validator starts emitting without ever getting a page stayed invisible
to CI. That is exactly how `ALP-B000` and `ALP-B099` went undocumented
until #1511 caught it by inspection.

New `scripts/check_diagnostic_emission_coverage.py` greps the emission
sites and fails if any has no `docs/diagnostics/<code>.md` page. Today's 11
emitted codes (`ALP-B000`-`ALP-B008`, `ALP-B010`, `ALP-B099`) already match
the 11 doc pages exactly, so this gate guards a currently-quiescent gap
against future drift rather than fixing a live one.
