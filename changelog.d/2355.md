### Fixed — no more `irq 14: nobody cared` storm on V2N/V2M when the CM33 runs (#2355)

The RZ/V2N ICU's CA55 error line is serviced only for GPT counter-overflow
bits, but the kernel left error group 0 (and the rest of group 1) unmasked.
As soon as the Cortex-M33 runs, group 0 bit 0 asserts; nothing acknowledges
it, so the line stormed at boot until genirq disabled IRQ 14, taking the GPT
overflow interrupts with it. Kernel patch
`0011-irqchip-renesas-rzv2h-mask-the-ICU-error-sources-the-handler-cannot-ack.patch`
unmasks only the GPT overflow bits and warns once about any error status
already pending at probe.
