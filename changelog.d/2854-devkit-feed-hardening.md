### Changed — the dev-kit opkg feed is edge-only and the packager publishes an allowlist (#2854)

`alp-devkit-feed-config` and `package-management` are now applied only in `alp-image-edge`; `alp-image-prod` fails its rootfs build if `ALP_DEVKIT_FEED = "1"`. `scripts/package_devkit_feed.sh` publishes an allowlist of Alp packages instead of every `all`/machine-arch ipk, fails on ipk names outside `[A-Za-z0-9._-]` or more than 1000 assets, verifies the signature against the committed public key, and refuses a non-empty `--out`. opkg is built with `sha256`. The docs now state that the feed only upgrades packages already in the image (no tune-arch closure).
