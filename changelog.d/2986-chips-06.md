### Fixed — tsl2591: mark the driver initialised only after the ENABLE write succeeds (#2986)

tsl2591_init() set initialised before writing ENABLE (PON|AEN). A failed
write returned the error but left the context readable, so
tsl2591_read_channels() could return ALP_OK with 0/0 counts from a
powered-down ADC. The flag is now set after the write succeeds.
