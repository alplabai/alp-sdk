### Added — V2N Linux driver and camera module entries for the Vision Components IMX568

**`ALP_CAMERA_CAM0 = "vc_mipi_imx568"` (mono) or `"vc_mipi_imx568c"` (colour) now selects a generated CAM0 devicetree fragment backed by a new `vc_mipi` kernel driver.** Kernel patch `0036-media-i2c-add-vision-components-mipi-csi-2-camera-module-driver.patch` carries the Vision Components GPL-2.0 module driver (NXP flavour, adapted to 6.1) with a `V4L2_CID_PIXEL_RATE` control so `rzg2l-csi2` can derive its D-PHY rate; `CONFIG_VIDEO_VC_MIPI=y` is added through `camera-sensors.cfg`. Mono/colour, lane rate and the RAW8/10/12 mode table are read from the module at probe, so both ids share one DT node. Only the 2-lane fragments exist (X-EVK CAM0 carries 2 lanes), a mono module cannot stream `Y12` (no receiver entry), and nothing has run on a module yet: see `docs/v2n-camera-csi.md`.
