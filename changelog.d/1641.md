### Added — dispatcher-side guard on the 41 previously-unguarded ops-vtable call sites (#1641)

15 of the 33 `src/*_dispatch.c` class dispatchers called an op-table function
pointer (`h->state.ops->read`, `->write`, `->start`, ...) with only `open`/
`close` checked `!= NULL` at backend registration — every other slot was
trusted to be populated. This is **not a live crash fix**: every in-tree ops
table that leaves a non-`close` slot NULL is protected structurally at open
today — `src/backends/spi/testing_drv.c`'s `target_open`/`target_transceive`/
`target_close` are all NULL, but `alp_spi_target_open()` rejects a NULL
`target_open` with `ALP_ERR_NOSUPPORT` before a target handle ever exists
(same pattern in `src/backends/i2c/testing_drv.c` and
`src/backends/usb/yocto_drv.c`), so no reachable NULL-deref existed in-tree
before this change. It closes a **contract gap** in the dispatcher/backend
ABI — the first partial vendor port that leaves a *reachable* op slot unset
would have hit it.

`adc_dispatch.c`, `camera_dispatch.c`, `counter_dispatch.c`, `dac_dispatch.c`,
`display_dispatch.c`, `gpu2d_dispatch.c`, `i2c_dispatch.c`, `i3c_dispatch.c`,
`jpeg_dispatch.c`, `power_dispatch.c`, `qenc_dispatch.c`, `rtc_dispatch.c`,
`spi_dispatch.c`, `uart_dispatch.c` and `wdt_dispatch.c` now guard all 41
sites the same way `storage_dispatch.c` already did: `ops->foo == NULL` ->
`ALP_ERR_NOSUPPORT`, exactly one `alp_handle_op_leave()` per exit path.
`<alp/adc.h>`, `<alp/counter.h>`, `<alp/dac.h>`, `<alp/rtc.h>` and
`<alp/wdt.h>` gained `ALP_ERR_NOSUPPORT` on the `@return` lists of the
functions where it is now a reachable outcome (the other seven headers
already documented it).

`tests/zephyr/conformance/src/main.c` adds a guard-mutation proof: it opens a
real UART handle, points it at a local copy of its own backend's ops table
with `write` NULLed, and asserts `alp_uart_write()` returns
`ALP_ERR_NOSUPPORT`. Reverting the guard under test turns a pass into a
SIGSEGV (`rc=-11`) that blocks the two ZTESTs after it — proof the guard is
load-bearing, not decorative. This exercises 1 of the 41 guarded sites; all
41 are the identical `ops->foo == NULL -> ALP_ERR_NOSUPPORT` shape, so the
one case stands for the class, but it is not per-site test coverage.
