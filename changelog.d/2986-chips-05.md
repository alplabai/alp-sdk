### Fixed — chips: a4988/drv8833/icm42670/max31855/max31865/rv3028c7 init, read and alarm hardening (#2986)

a4988_init no longer drives nENABLE low (coils stay de-energised until
a4988_set_enable) and returns write errors. drv8833_init coasts IN1..IN4
before releasing nSLEEP and returns write errors. icm42670_init writes the
accel/gyro FS_SEL bits (read-modify-write) so the chip matches the
dev->accel_fs / gyro_fs shadows. max31855_read returns ALP_ERR_IO when the
fault bit D16 is set. max31865_read_rtd reads RTD MSB/LSB in one
auto-incrementing burst. rv3028c7_set_alarm validates minute/hour/day/weekday.
