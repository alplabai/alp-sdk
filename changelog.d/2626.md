### Fixed — the library licence allowlist in the README can no longer drift from the schema (#2626)

`metadata/libraries/README.md` tells a maintainer to add a new SPDX id to both
`license.enum` in `metadata/schemas/library-v1.schema.json` and the README's
"Licence allowlist" block in the same change. Nothing checked that, so an id
admitted in the schema alone left every gate green.

`tests/scripts/test_library_layer.py` now has
`test_license_enum_matches_readme_allowlist`, which parses the README block and
asserts it equals the schema enum.

The Memfault paragraph in the same README carried a second, inline copy of the
list that had already drifted: it was missing `BSL-1.0`, `CC0-1.0` and
`MIT & Apache-2.0`. It now points at the "Licence allowlist" section, so the
README holds the list once.
