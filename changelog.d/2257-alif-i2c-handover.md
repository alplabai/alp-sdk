### Added — `alp,i2c-handover`: hand a shared Alif I2C controller from one M55 core to the other (#2257)

The Ensemble has one I2C1 block that both M55 cores can address. A `release` node (the core that configures a peripheral over it at boot, such as a display bridge) masks its interrupt, stops its controller and writes a flag word in always-on SRAM at the end of APPLICATION init; an `acquire` node (the core that owns the bus afterwards) waits for that flag at POST_KERNEL priority 0, ahead of every driver, reports on the console while it is missing without touching the bus, and clears the flag once it has it (SRAM0 survives a warm reset). The glue is `zephyr/soc-bridge/alif/i2c_handover.c`. An `acquire` image restarted alone waits for a release that will not come again; restart both, or write the magic `0x31433249` to the flag address.
