### Added

- `scripts/alp_project.py --emit scaffold` now accepts `--cores core_id:os[,core_id:os...]` as an alternative to `--template`: a selector that picks whichever catalog template's own `cores:` topology matches exactly, so an IDE wizard can name a core/OS mapping it already knows instead of hand-writing the scaffold's directory convention. `--template` is unchanged and remains fully supported; `--cores` resolves to the same template id and renders through the same `render_to_envelope()` path, so nothing already working changes. No exact topology match names the topologies that are on offer; more than one match asks for `--template` to disambiguate.
