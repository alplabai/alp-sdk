### Added — `examples/multicore/microros-ros2-v2n`: micro-ROS on the V2N M33 talking to ROS 2 on the A55 (#375)

A teaching example for ADR 0035 Option B: a micro-ROS node on the Cortex-M33 publishes `std_msgs/Int32` over a custom Micro XRCE-DDS transport backed by the ADR 0016 RPMsg endpoint, and an A55 bridge forwards it to an unmodified micro-ROS agent over UDP. Build-ready but not built or run on hardware; the README lists exactly what is untested.
