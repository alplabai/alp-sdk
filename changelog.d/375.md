### Added — `examples/multicore/microros-ros2-v2n`: micro-ROS on the V2N M33 talking to ROS 2 on the A55 (#375)

A teaching example for ADR 0035 Option B: a micro-ROS node on the Cortex-M33 publishes `std_msgs/Int32` over a custom Micro XRCE-DDS transport backed by the ADR 0016 RPMsg endpoint, and an A55 bridge forwards it to an unmodified micro-ROS agent over UDP. The M33 slice builds on Zephyr 4.4 / zephyr-sdk 1.0.1 with two carried patches (`m33_sm/patches/`) applied to a per-build copy of the pinned micro-ROS module (see `375-microros-zephyr44.md`); it has not been run on hardware, and the README lists exactly what is untested.
