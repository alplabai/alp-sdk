### Added — trace-runner HUD: an optional partner logo, built in only when `-DTR_PARTNER_LOGO=<header>` is passed (#2812)

`tools/genlogo.py` turns a partner's PNG or SVG into an ARGB4444 C header (scaled to fit 140 x 51, aspect kept); the HE build takes it as `-DTR_PARTNER_LOGO=<header>`, and the HUD draws the logo on every screen, centred on a plate in the HUD's own card style down the left edge, top-aligned with the power tile and level with the BEST / logo cards, above the name and invitation row. The plate is drawn last, so on the crash, initials and high-score screens, whose cards start at x 110, it overlaps the card's left edge and stays whole. It is composed into the HUD's existing left-middle tile and is in no tile's repaint key, so it adds no per-frame work. With no header nothing is compiled and the image is unchanged. No partner artwork is in this repository: `test_hud` and `test_hud_rot` build against a synthetic logo and check that the plate is the same pixels on every screen, and `a32/release/build-release.sh` refuses a build dir whose CMakeCache and elf disagree about whether a logo is built in.
