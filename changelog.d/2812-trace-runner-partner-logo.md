### Added — trace-runner HUD: an optional partner logo, built in only when `-DTR_PARTNER_LOGO=<header>` is passed (#2812)

`tools/genlogo.py` turns a partner's PNG or SVG into an ARGB4444 C header (in two sizes, scaled to fit 210 x 77 and 118 x 43 with the aspect kept, stored as 8-bit palette indices (half the raw pixels' flash, which the HE's 256 KiB ITCM image needs)); the HE build takes it as `-DTR_PARTNER_LOGO=<header>`, and the HUD draws the logo on every screen, centred on a plate in the HUD's own card style down the left edge, top-aligned with the power tile and level with the BEST / logo cards, above the name and invitation row. The full plate shows on play and the attract card; the crash, banner, initials and high-score screens, whose text starts nearer the left edge (the banner's at x 150), get the compact one, so no text is ever covered. The plate is drawn last, over those cards' backing. It is composed into the HUD's existing left-middle tile and is in no tile's repaint key, so it adds no per-frame work. With no header nothing is compiled and the image is unchanged. No partner artwork is in this repository: `test_hud` and `test_hud_rot` build against a synthetic logo and check that the plate is the same pixels on every screen, and `a32/release/build-release.sh` refuses a build dir whose CMakeCache and elf disagree about whether a logo is built in.
