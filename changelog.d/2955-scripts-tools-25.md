### Fixed — scripts: harden swd_probe, yocto_wic and provisioning ledger/EEPROM steps (#2955, #2956, #2957, #2989)

scripts hardening from the whole-SDK review. check_doxygen_coverage.py now fails on any missing @brief by default (--report-only opts out), so the quality registry and test-all.sh match pr-doxygen.yml. The swd_probe J-Link path requires a probe serial (flash_args.jlink_serial or ALP_JLINK_SERIAL, passed as -SelectEmuBySN), runs exec DisableAutoUpdateFW before an explicit connect instead of -AutoConnect, and reads the transcript instead of trusting rc==0. The yocto_wic host flasher refuses a target that is mounted or backs a mounted filesystem such as the host root disk. A bundle.json without a signature is recorded as unsigned:<version> and blocked from SHIPPABLE like a --build-dir unit. linux_target drops the page cache before the md5 readback of eMMC boot-partition and full-image rootfs writes. eeprom_manifest refuses before writing the EEPROM when a manifest.bin is already committed and --replace-identity is not set. (Refs #2989, #2955, #2956, #2957)
