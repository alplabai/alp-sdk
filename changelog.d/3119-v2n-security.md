### Added — opt-in Renesas security-package glue for the N48 SoMs (#3119)

**`meta-alp-sdk` can now build secure-boot, OP-TEE and Secure IP images for the N48 (`E1M-V2N104..106`, `E1M-V2M104..106`) when the Renesas RZ MPU Security Package v4.2.0.1 (`rz-security`) is in `bblayers.conf`.** Everything sits under `dynamic-layers/rz-security/` and is gated on the `alp-security` MACHINE_FEATURE, so an N44 build is untouched with the layer present; the glue pins the package version by file hash, reads signing keys only from `ALP_SEC_KEY_DIR` (unset by default, the signing task refuses without it), refuses `alp-security` on an N44 MACHINE (the `e1m-n48` machine include sets the feature for all six N48 machines), and never programs OTP. See `docs/v2n-security.md`; refuses the package's switches when the glue is not active, and strips the TA signing key from the OP-TEE dev kit. TF-A, OP-TEE and signing build on `e1m-v2n104-a55`; not run on silicon.
