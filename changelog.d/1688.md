### Fixed — cold-chain-monitor README's `models/`/`tests/` references dead-ended a scaffolded customer (#1688)

`scripts/alp_project.py --emit scaffold`'s doc-link rewriter (`scripts/alp_template.py`'s
`_scaffold_readme`) only rewrites markdown link syntax (`](../...)`) into an absolute
GitHub URL; it cannot reach a bare code span or a bare CLI argument. The `edge-ai` template
(`metadata/templates/catalog-v1.json`) vendors only `examples/ai/cold-chain-monitor`'s
`board.yaml`/`prj.conf`/`CMakeLists.txt`/`src/*`/`README.md` -- neither the example's own
`models/` subdirectory nor the repo-root `tests/unit/cold_chain/` ships with it -- so a
`tan init --template edge-ai` (or the equivalent `alp_project.py --emit scaffold`) customer's
README pointed at `models/README.md` and `tests/unit/cold_chain` with no way to resolve either.

Both referents are now real markdown links the rewriter picks up (verified against
`tests/fixtures/emit-snapshots/scaffold.edge-ai-v2n101.snap`, regenerated by
`check_emit_snapshots.py --update`): the Model section links `models/README.md`, and a new
sentence ahead of the Tests fence links `tests/unit/cold_chain` -- the `twister` invocation
itself is untouched. `examples/ai/cold-chain-monitor/src/main.c`'s two `models/README.md`
comments (lines 20 and 154 before this change) are unreachable by the rewriter either way and
are spelled out as the full repo-relative path instead, so the comment stays unambiguous once
the file is vendored away from its directory.

Same fix class as `examples/peripheral-io/i2c-master/README.md`'s dangling `i2c-scanner`
reference (#1705).

Filed from `tan-cli#821(a)`, which worked around the dead pointers with a
`DELIBERATE_EDITS` standing exception in `tests/parity/scaffold_byte_parity.py`; that
entry is declared to retire once this lands and tan-cli re-vendors this tree. The shipped
link text here does not byte-match tan-cli's own local correction, so the re-vendor's
parity capture (`scaffold.edge-ai-v2n101.snap` and its tan-cli-side counterpart) must be
regenerated, not assumed identical.

### Fixed — cold-chain-monitor's Model section rendered as two paragraphs, dangling the sentence before its own link

An adversarial review caught a rendering regression this fix's own commit introduced: the
explanatory `<!-- The ../cold-chain-monitor/ detour is deliberate: ... -->` comment landed
mid-sentence, at column 0 on its own line, between "No model is shipped (stub +
deterministic classifier/fallback). See" and the `models/README.md` link that completes it.
CommonMark treats an HTML comment at column 0 as an HTML block, which -- like a blank line --
can interrupt a paragraph; GitHub and every emitted scaffold README rendered the sentence and
its link as two separate `<p>` tags instead of one. The comment now sits above the paragraph
as its own block, separated by a blank line, so the sentence and its link render as a single
paragraph; the comment's wording is unchanged.
`examples/connectivity/mqtt-telemetry/README.md` carried the same defect, copied from this fix
by a later commit; see `changelog.d/1794.md` for that repair, including the strengthened pinning
tests and the regenerated `scaffold.edge-ai-v2n101.snap` golden this half of the fix also moves.
