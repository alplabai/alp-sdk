### Added — `rv3028c7_event_arm()` / `rv3028c7_event_disarm()`, and the AEN EVI wake now level-detects (#2811)

The `chips/rv3028c7` driver gains `rv3028c7_event_arm()` and `rv3028c7_event_disarm()`, which program Event Control 13h (`EHL`, `ET`, `TSS`, `TSOW` kept) and `EIE` / `EVF` in the order the Application Manual Sec. 4.11.1 gives; arming refuses with `ALP_ERR_BUSY` when the time stamp is bound to the backup switchover. The AEN STOP backend's `ALP_POWER_WAKE_EXT_EVENT` arm now writes the same Event Control values (active low, level detect with the 3.9 ms filter) instead of relying on the power-on edge setting, so a `MODULE_STBY` request that is already held low when the sleep starts re-latches `EVF` and wakes the part instead of being missed; a pulse shorter than about 4 ms may go unseen. Bench-pending.
