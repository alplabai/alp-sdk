### Added — E1M-V2N104..106 and E1M-V2M104..106: the RZ/V2N N48 (security option) SoMs (#3119)

**Six new SKUs on the `R9A09G056N48GBG`** (GPU + ISP + security IP), each the same PCB and memory tier as its N44 twin (V2N104/105/106 mirror V2N101/102/103, V2M104/105/106 mirror V2M101/102/103): SoM presets, `e1m-v2n104..106-a55` / `e1m-v2m104..106-a55` Yocto MACHINEs (thin `require` of the twin conf plus `include/e1m-n48.inc`), and generated CM33 board trees for `alp_e1m_v2n104_m33_sm` / `alp_e1m_v2m104_m33_sm`. Both N44 and N48 images ship the arm64 CE kernel crypto drivers; on N44 the CPU has no crypto extension so they do not bind, on N48 they are expected to bind (build-unverified, no N48 unit benched), so the SKUs are `preliminary`. Secure boot and the rest of the security IP need the Renesas RZ MPU Security Package (NDA) and are a follow-up. The stock `cortexa55` tune already builds every RZ/V2N machine userland, N44 included, with `-mcpu=cortex-a55+crypto`; that is a separate problem, Refs #3120.
