### Fixed — the local gate pins the alp-sdk Zephyr module for every stage again (#2491)

Since #2472 overlapped `scripts/test-all.sh`'s stages, each runs in a
background subshell, and the `export EXTRA_ZEPHYR_MODULES` that pins the
checkout as the alp-sdk module sat inside `stage_twister`, so it no longer
reached any other stage. On a host whose shell does not already export that
variable, `pytest-scripts` (`test_emit_kconfig_workspace.py`) and
`required-gate-scripts` (the `--emit kconfig` sweep) then failed with
`No board named 'alp_e1m_v2n101_m33_sm' found` and `Invalid BOARD`. CI
was unaffected because its workflows set the variable themselves.

The pin now runs once at top level, before any stage starts
(`scripts/test-all.sh:1603` ("pin_alp_zephyr_module")), and a test locks
that placement (`tests/scripts/test_test_all_worktree.py:275`
("def test_module_is_pinned_before_any_stage_forks")).
