### Fixed — `check_doc_drift.py` now catches removed chip-driver symbols and unknown board macros (#2346)

The doc-drift gate only knew `alp_`/`ALP_` symbols. It now also fails when
`docs/*.md`, `docs/boards/**` or `docs/soms/**`:

- name a symbol listed in `docs/abi/removed-symbols.json` that no
  `include/alp/**` header declares any more, unless the same line names
  the ledger's replacement (a rename note);
- name an `EVK_*`/`XEVK_*` macro that no `include/alp/boards/*.h` header
  defines.

`CHANGELOG.md`, `changelog.d/`, `docs/abi/**`, `docs/adr/**` and
`docs/superpowers/**` stay exempt.
