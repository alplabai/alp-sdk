### Fixed — ci: the twister apt .deb cache can now be saved (#3063)

`scripts/ci/apt-bounded.sh` now removes apt's `partial/` directory and `lock`
file from `APT_ARCHIVE_DIR` after a successful run. apt leaves both
root/`_apt`-owned, so `actions/cache/save` could not read them and abandoned
every save. The `.deb` cache from #2429 never existed, and each merge-queue
twister shard downloaded its host tools from the Ubuntu mirror. When that
mirror slowed down, the shards timed out (`apt-bounded: giving up ... rc=124`)
and the queue ejected every entry.
