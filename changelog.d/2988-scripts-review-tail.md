### Fixed -- scripts review tail: md5 reads the media, tokens use the deeper root, PSA errors surface, Mender poll variable (#2988, #2989)

**Five small script defects from the review passes are closed.** `LinuxTarget.md5()` now drops the page cache (`DROP_CACHES`) before its `dd | md5sum`, so `dxm1`'s check of a just-written file hashes what is on the storage rather than what is still cached (#2989). `_tokenize()` picks the deeper of `${PROJECT_ROOT}` and `${SDK_ROOT}` when both contain a path, so an SDK nested inside the project directory no longer tokenizes its own paths as `${PROJECT_ROOT}/<sdk>/...`, with `${PROJECT_ROOT}` kept on a tie. A failing `resolve_memory_map()` during `security.psa:` validation is now raised as the real error instead of being swallowed into an empty map that made every PSA reference fail as "does not resolve". `ota.poll_interval_s` on a Mender Yocto slice is written to `MENDER_INVENTORY_POLL_INTERVAL_SECONDS`, the variable meta-mender reads; the previous `MENDER_INVENTORY_INTERVAL` was read by nothing, so the setting never took effect. `docs/ota-device-contract.md` and the `iot-fleet-ota` README name the same variable and the 28800 s default.
