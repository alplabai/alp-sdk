### Fixed — the `--emit` goldens are now guarded by `pytest tests/scripts/`, not only by `test-all.sh` (#2023)

`tests/scripts/test_check_emit_snapshots.py` unit-tested only
`_normalize_host_paths`, so every committed golden under
`tests/fixtures/emit-snapshots/` was guarded **solely** by
`scripts/check_emit_snapshots.py` running inside `scripts/test-all.sh`.
Running `pytest tests/scripts -q`, reading green and pushing gave no
snapshot coverage at all.

Measured, not theorised: in the mutation review of #1365 split B (#2010),
mutants **A2** and **A3** survived `pytest tests/scripts/` entirely and were
killed only by that script. The fixtures carry the exact refusal text that
ships into `build/generated/alp/system_ipc.h` and `dts-reservations.dtsi`,
which is how #2009 — a refusal instructing an edit the same function
refuses — reached committed goldens and customer-visible generated output.

`tests/scripts/test_emit_snapshot_goldens.py` closes it the way the issue
prefers: it INVOKES the gate rather than reimplementing a fixture diff, so
there stays one source of truth for what "in sync" means. Five checks, and
the refusing direction of each is pinned rather than assumed —

- the gate itself runs under pytest and must report every surface
  byte-identical (mutation-proven: appending one line to
  `rpmsg-aen.system-manifest.snap` turns it red, reverting turns it green);
- a perturbed golden and a missing golden each return 1, exercised against
  a COPY under `tmp_path` with `CASES` narrowed to a single entry, so the
  committed fixtures are never written to and the check costs one emit
  rather than 37;
- `CASES` and the goldens on disk must be the same set in BOTH directions —
  a new case with no committed golden, and an orphaned golden no case emits
  any more, are drift that never shows up as a `DIFF`;
- both `--emit` surfaces that reach generated output (`system-manifest` and
  `build-plan`) keep at least one golden.

Costs ~10 s in a suite that already runs ~760 s, and that cost is the point:
without it the suite said nothing about the goldens.

One correction to the issue text while closing it: it describes "the four
golden fixtures under `tests/fixtures/emit-snapshots/`". There are **37**
`.snap` files there; four of them are the `.system-manifest` goldens. The
gap was wider than the issue stated, and this guard covers all 37.

Refs #2010, #2009, #1365. Closes #2023.
