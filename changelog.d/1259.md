### Added -- ONNX Runtime CPU floor enabled for the V2M and V2N images (#1259)

`alp-sdk` gains an `ort` PACKAGECONFIG (`-DALP_SDK_USE_ORT_CPU=ON
-DALP_SDK_ORT_REQUIRED=ON`, depends on the layer's own `onnxruntime` recipe)
that the V2M101/V2M102/V2M103/V2N101/V2N102/V2N103 MACHINE confs switch on
with `ALP_ENABLE_ORT_CPU`. On V2M the default is `0` while the DEEPX runtime
is on, because dx-rt already installs its own `libonnxruntime` 1.20.1 and the
layer's 1.28.0 would collide; set `1` to force it. `resolve_auto()` still
orders CPU last. Silicon passes per SKU are still owed.
