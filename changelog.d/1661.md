### Fixed — the ABI freeze gate read a header split as a removed symbol (#1661)

`scripts/abi_snapshot.py --diff` keys every symbol as `header::symbol`, so
relocating one between public headers — a header split, or lifting a hand-written
block into its generated `*_routes.h` sibling — read as `REMOVED` + `ADDED`. The
"ABI freeze gate vs the last released snapshot" step in
`.github/workflows/pr-generated-files.yml` greps for `^  REMOVED ` and fails the
PR, so a move that cost no consumer anything blocked as if a symbol had been
dropped.

The workflow already documents this shape against its own predecessor: comparing
to `v0.1` left *"~200 REMOVED/CHANGED entries ... none of them a real
regression"*, citing "header splits e.g. `dac.h` out of `adc.h` in v0.8.0".
Moving the baseline to the last release fixed the accumulation but not the
move-blindness, so every future split hit it again.

`--diff` now reports `MOVED` when the symbol name and category are unchanged,
its recorded hash is unchanged, **and** the old header still `#include`s the new
one — so a translation unit including the old header still sees it. `MOVED` does
not trip the gate; `REMOVED` still does.

**Reachability is proven from the tree, not assumed, and two restrictions on how
it is proven both err toward `REMOVED`.**

The first was a live security defect in the first cut of this change, not a
theoretical one. A naive scan recorded `#include` lines inside a false `#if` arm
that the preprocessor would never follow — a parser differential between this
scanner and `cpp`. `include/alp/board.h` selects between
`alp/boards/alp_e1m_x_evk_routes.h` and `alp/boards/alp_e1m_evk_routes.h` with
mutually exclusive arms and an `#else #error`; both were recorded as edges. A
symbol moved out of `board.h` into either routes header therefore read as `MOVED`
while every consumer building the **other** board had genuinely lost it — a real
ABI break, reported safe, by the gate whose only job is catching exactly that.
Demonstrated end-to-end before the fix, `rc=0` with the gate silent. Only
unconditional includes now count. The condition is never evaluated, only its
presence: *is this include unconditional?* is answerable from the text, *is this
arm taken?* is not, and guessing would rebuild the same differential one level up.

The include guard is **discovered** rather than assumed to be the outermost
conditional. A `#pragma once` header has no guard, so its first `#if` would
otherwise be mistaken for one and its conditional includes would count again; a
header opening a top-level `#if` above its guard would push real conditionals
down a level and lose its unconditional includes instead. Both shapes are pinned
by tests.

The second restriction is that reachability is **one hop**. A symbol moving to a
header reachable only transitively stays `REMOVED` — 136 transitive-only header
pairs exist in `include/alp/` today, so this is a real limit, and it is a false
`REMOVED`: noise a human resolves at review rather than a silent break.

The persisted snapshot schema is deliberately unchanged. The include graph is
computed fresh from disk inside `--diff` and never written, because
`pr-generated-files.yml` byte-diffs the regenerated current snapshot against the
committed copy — any schema addition would redden that gate regardless of
content. `--output` writes byte-identical bytes to before.

`docs/abi/README.md` documents the `MOVED` verdict and both restrictions, and
`tests/scripts/test_abi_snapshot_freeze_gate.py` runs the workflow's own step
against a real relocation, so the `MOVED` ↔ `grep -q '^  REMOVED '` coupling is
pinned at the gate level and not only in `diff()`'s unit tests.
