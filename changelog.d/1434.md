### Fixed — `test_verify_west_patches.py`'s `west` shim was not executable on Windows, failing all 13 of its tests on `dev`

The fixture wrote its stub `west` as `#!/usr/bin/env bash` with the exec bit.
Windows cannot spawn that: `subprocess` raises

```
FileNotFoundError: [WinError 2] The system cannot find the file specified
```

so every test in the file failed on `python-smoke (windows-latest)` — `13
failed, 2722 passed, 86 skipped` — while passing on ubuntu and macos.

The shim is now a Python script, plus a `.bat` wrapper on Windows (a `west`
with no extension is not spawnable there; `PATHEXT` picks up `.bat`).

Skipping the module on Windows would have been cheaper and wrong:
`scripts/bootstrap.ps1` invokes `verify_west_patches.py`, so this is code
Windows users run, and a skip there would be coverage removed rather than a
platform that genuinely does not apply.
