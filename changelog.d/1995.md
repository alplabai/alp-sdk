### Fixed — `scripts/test-all.sh` could never pass on Windows (#1995)

`bash scripts/test-all.sh` always failed its `[yocto-build-and-ctest]`
stage on a Windows host:

```
src/yocto/inference_drpai.cpp:117:10: fatal error: sys/ioctl.h: No such file or directory
[yocto-build-and-ctest] FAIL (exit=1)
```

`src/yocto/inference_drpai.cpp:115-118` hard-includes `<fcntl.h>`,
`<linux/drpai.h>`, `<sys/ioctl.h>` and `<unistd.h>`, and
`tests/yocto/CMakeLists.txt` compiled it into
`alp_test_inference_drpai_regression` on every host. `sys/ioctl.h` does
not exist on Windows, so the stage — and therefore the whole script —
could not go green there.

That block's own comment named the assumption behind it: "no platform
guard here beyond the one this whole `yocto` leg already implies (issue
#1747's CI gate runs on ubuntu-latest)". The implication holds for CI
and not for `test-all.sh`, which at `scripts/test-all.sh:1029-1033`
skips the yocto leg only for `--target dev` and otherwise runs it
wherever it is invoked.

This mattered beyond a cosmetic red. The repo's workflow is local-first
CI on **both** Windows and WSL; a stage that can never be green on one
of them trains the reader to treat its `FAIL` as noise, which is exactly
how a genuine failure in that stage would be waved through. It also made
a Windows run's `REAL_RC` useless as a single go/no-go signal.

The `alp_test_inference_drpai_regression` target is now defined only
when `CMAKE_SYSTEM_NAME STREQUAL "Linux"`. The target is guarded rather
than the whole leg on purpose: the sibling `alp_test_inference_ort_
regression` and `alp_test_inference_deepx_regression` targets are
host-portable and still build and run on Windows, so the leg keeps its
coverage there. On a non-Linux host CMake now prints a named skip
pointing at the ubuntu-latest job that does cover it, matching how
`[bash32-parse]` and the stage's own `zcbor not found` gap already
report themselves.

Verified on Windows 11 (MSYS2/Git Bash) at `2b9001176` + this change:
`cmake -B <dir> -S . -DALP_OS=yocto -DALP_BUILD_TESTS=ON -G "Unix
Makefiles"` configures with the skip message, `cmake --build` exits 0,
and `ctest --output-on-failure` reports `100% tests passed, 0 tests
failed out of 10` — the same stage that previously died at
`make: *** [Makefile:101: all] Error 2`.
