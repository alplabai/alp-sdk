### Fixed — merge-queue entries now re-grade changelog citations against the tree they will land (#2206)

A dedicated `merge_group` workflow now runs only
`scripts/check_changelog_citations.py`, with `DIFF_BASE` set to the merge
group's base SHA. Its static `changelog citations · merge queue` job name is
suitable for a required branch-protection context, so a citation displaced by
a newer `dev` commit is caught before the queued tree lands without putting the
full metadata-validation workflow on every queue entry. Structural tests pin
the trigger, base selection, full-history checkout, static context name, and
the separation from `pr-metadata-validate.yml`.
