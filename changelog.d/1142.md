### Documented — the DT gpio-hog / CM33-SPI collision named in #1142 is already resolved; two items remain open (#1142)

Re-verified #1142's claim against `dev` @ `2b817532`. The specific technical
collision the issue names — a Linux `gpio-hog` at
`meta-alp-sdk/recipes-kernel/linux/linux-renesas/e1m-x-evk.dtsi` claiming
P9.6, colliding with the CM33-owned GD32 supervisor SPI's SCK7 on the same
pad — was already fixed by commit `7b44451d1` ("stop claiming CM33-owned
P9.6 in the USB OVC hog", 2026-06-12), months before this issue's 2026-08-05
rewrite. The current `usb-ovc-disable-hog` claims only PB.1; P9.6/SCK7 is
untouched by Linux and carries an explicit in-file comment (`e1m-x-evk.dtsi`
around the hog) warning against ever re-claiming it. The CM33 board pinctrl
(`sci7_spi_pins` in both `*_m33_sm-pinctrl.dtsi` files) owns P96 as SCK7 —
confirmed by reading both sides; no code change needed here.

The two remaining `gpio-hog` entries on the Linux side —
`sd1-pwr-en-hog` (PA.3, microSD slot power enable) and
`usb-ovc-disable-hog` (PB.1, parks the unusable usb30 OVC sense input,
errata E3) — are not shown to conflict with anything the CM33 or the A55
needs; both hogs serve a documented electrical purpose and neither pad
appears in the CM33 pinctrl files. No line was found in this pass that the
A55 needs and cannot reach because of a hog.

**Left open, needs a maintainer decision:** whether these two remaining
hogs should still exist now that `src/yocto/peripheral_gpio.c` provides a
real chardev-v2 GPIO backend able to open any chip/line pair — per-hog, this
is a product/hardware call (e.g. does anything ever need `sd1-pwr-en` or the
OVC-disable line released to userspace?), not something determinable from
the tree alone.

**Tracked separately, not in this change's scope:** #1157 — making per-core
pad ownership expressible in `metadata/pinmux/v2n.yaml` (currently every
Renesas-owned pad reads `owner: "renesas"` uniformly across all 145 rows,
so this class of collision has no metadata-level gate). That work is its
own unit.
