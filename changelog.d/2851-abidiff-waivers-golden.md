### Added — `abidiff` waiver file and golden tests from real libabigail output (#2851)

**`scripts/check_abidiff.py` reads reviewed, time-boxed ABI exceptions from `docs/abi/abidiff-waivers.yaml` (`symbol`, `kind`, `reason`, `issue`, `until`).** A change covered by a valid waiver is dropped and printed as `waived:`; any un-waived change still fails, and a malformed entry, a missing reason or issue, or a waiver whose `until` minor has been reached by `metadata/sdk_version.yaml` fails the gate. The SONAME-only suppression never masks an abidiff error bit (exit 1/2), and a waiver never does either. Tests now run against real `abidiff` 2.9.0 reports (removed function, changed signature, struct size change, removed and changed variable, SONAME-only) recorded under `tests/scripts/fixtures/abidiff/`, replacing the hand-written SONAME fixture. The gate stays advisory.
