### Fixed — a citation whose path starts with a dot was silently unchecked (#1755)

`scripts/check_changelog_citations.py`'s `_CITATION` path group began
`[A-Za-z0-9_]`, so a path whose first character is a dot never matched the regex
at all. Every `.github/workflows/*.yml:NNN` citation was therefore invisible to
the gate -- not reported, not skipped, simply never seen, while the summary line
reported a confident count that excluded them.

#1750 widened the blast radius by extending this gate to scan `CHANGELOG.md`,
where several such citations already ship. It also set a trap for anyone fixing a
citation correctly: rewriting a bare `cross-platform-zephyr.yml:156` into its real
repo-relative `.github/workflows/cross-platform-zephyr.yml:449` REMOVED it from
the gate's view, so doing the right thing reduced coverage.

The path group now accepts an optional single leading dot. The regex is anchored
on backticks at both ends, so this cannot widen it into prose. With the
previously-invisible citations now in scope the gate resolves 109 citations across
55 fragments plus `CHANGELOG.md` with zero errors -- every one that had been
shipping unchecked resolves correctly. Two unit tests pin the dotted and undotted
forms.
