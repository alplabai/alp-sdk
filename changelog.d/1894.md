### Added — the first tier-2 bench perf points in `metadata/model_perf/` (#1894)

Three points were measured on E1M-V2M103 2026W38-0001 on 2026-09-28. Each follows `docs/bench/model-perf-capture.md`: 5 warm-up invokes discarded, then back-to-back good invokes timed with `alp_inference_last_invoke_latency_us()`:

| backend | model | mean | p95 | runs |
|---|---|---|---|---|
| `deepx_dxm1` | yolo11n (dx-com 2.3.0) | 45.47 ms | 46.16 ms | 50 |
| `drpai` | YOLOX-S/VOC sparse70 (DRP-AI Translator i8 v1.12) | 40.05 ms | 40.09 ms | 50 |
| `cpu` (ONNX Runtime 1.20.1) | YOLOX-S/VOC | 1668.5 ms | 1674.1 ms | 30 |

All three run on the A55 cluster with the model in DDR, so there is no on-chip SRAM arena (`req_sram_kib` / `arena_bytes` = 0). The unit is bench-only, and each point's `capture.notes` records that. No Ethos-U point is included: the vela-profile question in the capture doc still blocks those.
