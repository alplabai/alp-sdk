### Changed — `pytest tests/scripts/` no longer runs at its CI time cap: five slow test files stop repeating expensive work (#2328)

`pr-metadata-validate`'s `Pytest -- linter + schema regression + topology defaults`
step runs the whole `tests/scripts/` suite under `timeout-minutes: 20`, and on
`dev` it had reached 19 to 20 minutes, so unrelated PRs went red at random on a
timeout. Per-line CI timestamps showed that 51 of the 4,411 tests took 15.2 of
the 19.9 minutes. Five test files accounted for most of that. None of them was
slow for a good reason; each repeated the same expensive work or waited for
nothing.

- `test_alp_quality.py`: `test_run_profile_pr_matches_registry_selection`
  checks WHICH gate scripts the `pr` profile selects, but it executed every one
  of them. It now stubs the gate-execution subprocess call, while
  `run_profile`'s real selection and iteration still run. The assertion is
  unchanged, and dropping a task from the selection still fails it.
- `test_gen_catalog.py`: the full catalog was rebuilt in every test. It is now
  built once per module. `test_render_is_deterministic` still compares two
  independent builds (the cached one against a fresh one), never the cache
  against itself.
- `test_check_zephyr_conf_parity.py`: two tests ran the identical full-corpus
  gate separately. They now share one module-scoped run.
- `test_gen_portability_matrix_libraries.py`: five tests each regenerated the
  whole matrix. They now share one module-scoped generation, and the
  determinism test compares it against a fresh generation.
  `test_gen_portability_matrix.py` already worked this way and is unchanged.
- `test_apt_bounded_wrapper.py`: the tests waited out 12 s attempt slices
  against a fake `apt` that runs `sleep 9999`. They now pass smaller values
  through the wrapper's existing `APT_ATTEMPT_TIMEOUT` / `APT_STEP_BUDGET`
  overrides. The #1604 regression test still straddles the wrapper's fixed
  10 s give-up floor. `scripts/ci/apt-bounded.sh` itself is unchanged.

Locally the six files went from about 420 s to 104 s, and all 71 of their tests
pass. No production script changed, and no assertion was removed or loosened.
