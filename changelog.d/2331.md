### Added — E1M-X-EVK carrier audio: TAS2563 stereo ALSA card on V2N-family Linux (#2331)

`meta-alp-sdk/recipes-kernel/linux/linux-renesas/e1m-x-evk.dtsi` gains the
SoC audio side for the carrier's stereo TAS2563 smart-amp pair (U27 @0x4D
left, U28 @0x4E right, on I2C0 + I2S0 through the TMUX1574 path-mux): I2S0
pinctrl (SSIU1/SSI1 SCK/WS/SDATA at PFC function 7), `&audio_clkb {
clock-frequency = <24576000>; };` for the on-module 5L35023B SE3 24.576 MHz
feed, `&rcar_sound` enabled with an SSI1 playback endpoint, and both
`ti,tas2563` codecs on ONE audio-graph-card2 `multi` link (SSI1 fanned out
to both amps, so both follow the stream's hw_params and DAPM power
sequencing). Each codec endpoint declares 2 x 32-bit TDM slots to match
rsnd's fixed 32-bit SSI word. `tas2563-audio.cfg` enables
`CONFIG_SND_SOC_TAS2562=y` and pins `CONFIG_SND_AUDIO_GRAPH_CARD2=y` for
`e1m-v2n101`/`e1m-v2m101`.

Kernel patch `0009-ASoC-tas2562-reset-the-amplifier-at-probe.patch`: the
6.1 driver's register cache assumes POR state (including page 0) but never
resets the part. SD_N is one shared net that does not toggle across a warm
reboot, so the amps kept the previous boot's page and settings -- gain
writes were dropped as cache no-ops and page-0 writes landed in page 2.
The driver now selects book 0 / page 0 and issues SW_RESET at probe.

A new `alsa-state` bbappend ships boot-time mixer defaults: each amp's
"ASI1 Sel" set to its own slot (Left/Right), and Amp Gain at its lowest
level (8.5 dBV) instead of the silicon default (16 dBV, ~10 W peak into
4 ohm).

Bench-verified on E1M-V2M103 (2026-09-27): card registers
(`rsnd-dai.0-tas2562-amplifier_multi`), both amps go software-shutdown ->
active with a 48 kHz stream and back, TDM detect reads 48 kHz / 64 bits per
frame on both, no live faults, and the mixer defaults are restored at boot.
Acoustic output is not yet confirmed by ear.

Still open on #2331: I2C-address ownership between this kernel codec
binding and the SDK's userspace `chips/tas2563` driver (no live conflict
today -- no `alp-chips` PACKAGECONFIG enables it on these MACHINEs).
