### Fixed

- E1M-X EVK (V2N family): re-enable the TAS2563 ALSA card, now playing out of SSI2's data line (P47 -> `I2S0_SDO` -> amp SDIN) with SCK/WS from SSI1 (P44/P45) (#2331). RZ/V2N SSIU_SSI_MODE1.ssi2_pin = 110b (R01UH1072EJ0120, 8.5.2.3.16) makes this possible; new kernel patch 0014 teaches rsnd the SSI2-under-SSI1 parent case (`alp,shared-pin-ssi1` on `&ssi2`). P46 (the amps' SDOUT net) is never muxed. Bench listen still pending.
- E1M-X EVK (V2N family): drop `clk_a`/`clk_c` from the `&rcar_sound` clock list (#2331). Audio_CLKA (AUDIO_EXTAL oscillator) and Audio_CLKC are not fed on this SoM/carrier, so the CPG never raises their CLK_ON monitor and playback start failed with `Failed to enable CLK_ON` / `__pm_clk_enable ... error -110` (538 ms periods). The card now runs from Audio_CLKB only. Bench, E1M-V2M103: 2 s of 48 kHz stereo plays in 2.06 s wall time with no -110 (it was 538 ms per period before). Kernel patch renumbered 0013 -> 0014 because the CAN-FD bring-up (#2341) carries 0013.
