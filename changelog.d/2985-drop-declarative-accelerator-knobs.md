### Removed — per-library accelerator Kconfig knobs that gated nothing (#2985)

**The `ALP_TFLM_ETHOS_*`/`_HELIUM`/`_NEON`/`_DMA_COPY`, `ALP_CMSIS_DSP_*` (non-scalar), `ALP_LITTLEFS_*_DMA`, `ALP_LVGL_*` (non-SW), `ALP_MBEDTLS_*`/`ALP_BEARSSL_*` (non-pure-C), `ALP_MINIMP3_*`/`ALP_OPUS_*`, `ALP_MADGWICK_FPU`/`_TMU`, `ALP_PID_FPU`/`_TIMER`, `ALP_MODBUS_*_DMA`, `ALP_COAP_MBEDTLS`/`_OSCORE`, `ALP_LWS_*` and `ALP_U8G2_*` accelerator symbols are gone.** No source, CMake or devicetree file read them, so `board.yaml` `libraries:` selections recorded accelerator claims in `alp.conf` that compiled nothing. Their `accelerators:` entries are removed from `metadata/libraries/*.yaml`, so the orchestrator no longer emits them; SW-floor markers and the `ALP_GFX_COMPAT_*` knobs (which do gate code) are unchanged. Inference backend selection is unaffected (`CONFIG_ALP_SDK_INFERENCE_*`).
