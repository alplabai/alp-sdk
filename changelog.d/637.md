### Added — single-source the EVK mux-select enums from metadata, closing #515's last gap (#637)

`include/alp/boards/alp_e1m_evk.h` still hand-authored six mux-select /
IO-expander-pin enums -- `evk_sdio_select_t`, `evk_i2s_select_t`,
`evk_usb2_select_t`, `evk_pcie_select_t`, `evk_pcie_ioexp_pin_t`, and
`evk_ioexp_pin_t` -- duplicating hardware facts that `i2c_devices:` (#515)
and `overlay_pins:` (#1636) had already moved to
`metadata/boards/e1m-evk.yaml` for every other EVK-board fact class.
`evk_cam_select_t` (the MIPI CSI camera mux) is deliberately excluded --
out of this slice's scope.

New `mux_enums:` block in `metadata/boards/e1m-evk.yaml`
(schema: `metadata/schemas/board-preset.schema.json`'s new
`mux_enum_entry` `$def`) is the single source of truth for each enum's
name, doc, and per-enumerator name/value/doc.
`scripts/gen_board_header.py` grows `_emit_mux_enums()`, wired into
`emit_board()` alongside the existing `_emit_i2c_devices()` /
`_emit_overlay_pins()`, and emits one `typedef enum { ... } <name>;`
block per entry into the generated
`include/alp/boards/alp_e1m_evk_routes.h` -- column-aligned per enum
(resets between enums, mirroring `Consecutive` clang-format alignment)
and rejecting duplicate enumerator values at generation time (the schema
cannot express cross-item uniqueness within a `values:` list, and a
silent collision reads as a typo in the generated header, not a build
error).

Every emitted enumerator name/value/doc matches the previously
hand-authored constant byte-for-byte -- the ABI snapshot regen
(`docs/abi/v0.16-snapshot.json`) confirms all six typedefs as `MOVED`
(`alp_e1m_evk.h` -> `alp_e1m_evk_routes.h`), never `CHANGED`.
`alp_e1m_evk.h` keeps only prose describing the hardware; the enum
definitions now come from the generated header, same pattern as #515's
I2C-address migration. No pin, address, or mux-select value moved --
this closes #515's single-source goal for the EVK board (mux enums were
the only remaining hand-authored hardware-fact class; overlay-pad
indices were already lifted by #1636 before this slice started).
