### Added — aen-trace-runner runs on the Riverdi RVT121 12.1" LVDS panel (#2257)

`-DTR_PANEL=rvt121 -DTR_PANEL_HZ=30` builds the game for the 1280x800 landscape panel (shield `e1m_evk_rvt121hvdfwca0`) in its default `TR_RENDER=A32` mode. The game keeps its 720x1280 portrait geometry; the A32 renderer and the HUD write it rotated into a 1280x720 window centred on the panel, so a panel mounted on its side shows it upright. `TR_PANEL_ROTATE=90|270` (default 90) picks the direction, and the A32 renderer must be built with the same value (`make -C a32/renderer TR_PANEL_ROTATE=...`). The framebuffer addresses and sizes do not move. `TR_CAMERA` and `TR_INPUT_NPU` are refused with this panel. The default `TR_PANEL=rk055` build is unchanged. Build-only, not run on hardware.
