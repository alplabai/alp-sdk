### Fixed — `write_emmc_boot` wrote the boot loader to the eMMC boot partition that is never booted (#2624)

- **Wrong partition.** `write_emmc_boot` released `bl2_mmc` and the FIP with `dd` into `/dev/mmcblk<N>boot1`, which is eMMC boot partition 2. EXT_CSD[179]=`0x08` (set by `bootstrap` and by `mmc bootpart enable 1 0`) boots boot partition 1, which Linux names `mmcblk<N>boot0`. Its probe md5-checked the same wrong device, so it reported success. Affected: any unit whose boot loader was rewritten by `write_emmc_boot` without `bootstrap` (for example one re-provisioned from Linux with the pre-Linux steps skipped): it kept booting the old boot loader. A full run was not affected, because `bootstrap` wrote the right partition (Flash Writer `EM_W` area 1) with the same bytes.
- **Fix.** The write, its size check, `force_ro`, the probe and the census md5s now use `mmcblk<N>boot0`, from one constant (`EMMC_BOOT_PART`). Tests fail if the write or the probe touch `boot1`. Not yet benched.
