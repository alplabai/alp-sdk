### Fixed — host scripts: yocto_wic refuses mounted targets, unsigned bundles never ship, doxygen coverage fails by default (#2956, #2957)

**`scripts/flash_backends/yocto_wic.py` refuses a target block device that is mounted or backs a mounted filesystem (such as the host root disk), and `scripts/provision/ledger_out.py` records a `bundle.json` without a signature as `unsigned:<version>` and blocks it from SHIPPABLE like a `--build-dir` unit.** `scripts/check_doxygen_coverage.py` now fails on any missing `@brief` by default (`--report-only` opts out), so the quality registry and `test-all.sh` match `pr-doxygen.yml`. `linux_target` drops the page cache before the md5 readback of eMMC boot-partition and full-image rootfs writes, and the EEPROM manifest step refuses to overwrite a committed `manifest.bin` without `--replace-identity`. Split out of #3012, which keeps only the `swd_probe` J-Link change (#2955) until a working GD32 SWD probe is on the bench.
