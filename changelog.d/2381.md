### Fixed — `/dev/drpai0` is group-accessible, so non-root DRP-AI apps can open the NPU (#2381)

The DRP-AI driver creates `/dev/drpai0` as `crw------- root`, and neither
meta-rz-drpai nor the BSP ships a udev rule. A non-root
`alp_inference_open(.backend = DRPAI)` therefore failed at `open()` and
reported `ALP_ERR_IO`, the same code as a missing node.

A new `alp-drpai-udev` recipe installs `99-alp-drpai.rules` (`/dev/drpai*`
→ `0660 root:video`, the same policy as the DEEPX `/dev/dxrt*` nodes).
`alp-image-common.inc` installs it together with the rest of the DRP-AI
runtime (`ALP_RZ_DRPAI_INSTALL`). On E1M-V2M103 board #1 the rule turns the
node into `crw-rw---- root video`.
