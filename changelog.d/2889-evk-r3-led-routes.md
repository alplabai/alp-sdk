### Added — E1M EVK hardware revision `r3` (2641-R3) with its own RGB LED routes (#2889)

**`metadata/boards/e1m-evk.yaml` gains `hw_revisions.r3` with `route_overrides` (red = `E1M_GPIO_PWM3`/`E1M_PWM3`, green = `E1M_GPIO_PWM0`/`E1M_PWM0`, blue = `E1M_GPIO_PWM1`/`E1M_PWM1`) and `route_removals: [EVK_PIN_ENCODER_SW]`; the 2641-R3 encoder header has no push switch.** `scripts/gen_board_header.py` emits them in `alp_e1m_evk_routes.h` under `#ifdef ALP_E1M_EVK_HW_REV_R3`, so builds without that define and the default revision `r2` (bench-verified 2026-07-28) resolve exactly as before. `scripts/abi_snapshot.py` skips those guarded blocks too, so the ABI snapshot keeps the default (r2) values. The RTL8211F(D)(I)-VD-CG PHY driver docs now state the family covers the fitted RTL8211FI-VD-CG.
