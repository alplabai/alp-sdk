### Fixed — public-headers: reject out-of-range update-log status, add missing ABI_STATUS macros, correct update-log/wdt/version docs (#2981)

alp_update_log_append()/alp_update_log_append_boot() now reject an alp_update_log_entry_t whose status is outside alp_update_status_t with ALP_ERR_INVAL instead of truncating it to one byte (256 was silently stored as ALP_UPDATE_STATUS_CONFIRMED and hashed into the tamper-evident chain). The update_log.h return-code docs now match the dispatcher (NULL log is ALP_ERR_INVAL, closed log is ALP_ERR_NOT_READY, a backend without an append op is ALP_ERR_NOT_IMPLEMENTED). version.h gains ALP_ABI_STATUS_I3C/JPEG/AHRS/PID/I2C_REGFILE (all ABI-EXPERIMENTAL) so feature tests on those headers no longer silently evaluate false, and alp_version_string() documents the -rcN form. wdt.h documents that the Yocto backend disarms the watchdog on alp_wdt_close() while Zephyr does not.
