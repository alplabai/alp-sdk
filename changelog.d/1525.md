### Fixed — `check_changelog_citations.py`'s foreign-repo skip list was incomplete, hard-failing correct cross-repo citations (#1525)

Same defect and same fix as #1522: `_FOREIGN_PREFIXES`'s `python/tan/` entry
widened to the whole top-level `python/` directory (`crates/` and
`contract/` were already whole top-level dirs, unchanged), so any citation
into tan-cli's `python/` tree — `python/tan/...`, `python/tests/...`,
`python/scripts/...` — is SKIPPED as foreign instead of hard-failing as "no
such file in this tree". A gate that fails correct input trains people to
strip the citation rather than trust the gate; see `changelog.d/1522.md` for
the full evidence and the mutation-proof.
