### Fixed — release notes told users to verify the tarball with `gh attestation verify`, which fails for every release (#3058)

`release.yml` publishes SLSA L3 provenance only as the
`alp-sdk-vX.Y.Z.tar.gz.intoto.jsonl` release asset, so
`gh attestation verify` returned HTTP 404 from the GitHub attestations API
for every release. The release-notes template, the v0.17.0 and v0.18.0
notes, `docs/release-policy.md` and `docs/v1.0-readiness.md` now give the
`slsa-verifier verify-artifact` command that `release.yml` already
documents.
