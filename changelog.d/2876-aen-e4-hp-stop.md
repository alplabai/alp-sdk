### Added — Alif SE STOP backend on the E4 M55-HP (E1M-AEN401) (#2876)

`CONFIG_ALP_SDK_POWER_ALIF_SE` now also builds for `SOC_AE402FA0E5597LE0_RTSS_HP`, and the backend registers for `alif:ensemble:e4` as well as `alif:ensemble:e8`. On the E4 HP it writes the HP's own `RTSS_HP_CTRL` / `RTSS_HP_RESET` pair (AON 0x1A604000 / 0x1A604004); before, only the E8 HP symbol selected that pair. The AE402FA0E5597 DFP gives the same register bases as the E8 for everything else the backend touches. `examples/aen/aen-power-stop` builds for the AEN401 HP with its own overlay (se_service, lptimer0, rtc0, lpgpio) and `CONFIG_ALP_SDK_SOM_POWER=y`. Not yet run on an Alp Lab bench. Known gaps on E4: no `bkram` node, so the wake record is not retained and `alp_power_boot_wake_info()` reports no STOP wake; and no `alp,som-power` node on the AEN401 board, so no on-module domain is quiesced before STOP.
