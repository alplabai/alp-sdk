### Fixed — changelog citations no longer break when unrelated lines shift above them (#2350)

`scripts/check_changelog_citations.py` treated a citation's line number as
binding, so any edit that inserted or removed lines above a cited line failed
the gate, even though the quoted anchor text was unchanged. The anchor text is
now authoritative and the line number advisory:

- Text inside the cited range passes, as before.
- Text found exactly once elsewhere in the file passes, with a
  `note: ... anchor now at line N` line. `--fix` rewrites the citation.
- Text found more than once fails as ambiguous and lists the lines.
- Text absent from the file fails, as before.
