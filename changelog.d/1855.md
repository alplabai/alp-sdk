### Fixed — scaffolded `board.yaml`/`src/*.c` comments named an alp-sdk-only path bare, unresolvable outside the SDK tree (#1855)

`--emit scaffold`'s content-adaptation pass (`alp_template.render_to_envelope`)
only ever rewrote a bare alp-sdk-tree-relative cross-reference
(`docs/cc3501e-bridge.md`, `examples/v2n/v2n-temp-sensor`, ...) inside
README.md — via `_scaffold_readme`'s markdown-link rewriter. A `board.yaml` or
`src/main.c` **comment** names the same kind of reference in plain prose, with
no `[...](...)` around it, so it was never touched and survived a scaffold
verbatim: `iot`'s board.yaml/src/main.c both said "(see
docs/cc3501e-bridge.md)"; `sensor`'s board.yaml/src/main.c both said "see
examples/v2n/v2n-temp-sensor for ..."; `edge-ai`'s src/main.c said "(see
examples/ai/cold-chain-monitor/models/README.md)" — none of those paths exist
in a customer's copied-out project.

`multicore-mailbox`'s README carried a related but separate bug: its
`west build -b <board> examples/multicore/mproc-mailbox/peer` line names a
*subpath* of the template's own `example_path`, which the existing bare-
mention rewrite (`example_path` -> `.`) never matched (its right-hand `\S`
boundary failed on the trailing `/peer`), so it survived un-rewritten too.

Added `_scaffold_bare_repo_paths()` — the same `docs/*.md`/`examples/<...>` ->
absolute GitHub URL rewrite `_scaffold_readme` already gives a markdown link,
now also run on `board.yaml` and every `src/*.c`/`src/*.h` in
`render_to_envelope()` — and widened `_scaffold_readme`'s bare `example_path`
match to capture and keep a trailing `/<subpath>`, rewriting it to
`./<subpath>`. `diagnostics` and `minimal` were checked against the same
methodology and carry no such reference today; left unchanged.

`tests/fixtures/emit-snapshots/scaffold.{peripheral,sensor,edge-ai}-v2n101.snap`
and `scaffold.multicore-mailbox-aen801.snap` regenerated via
`scripts/check_emit_snapshots.py --update` to match (`peripheral`, not named
in the original report, carries the same bug class in its `board.yaml` and is
fixed by the same general pass).
