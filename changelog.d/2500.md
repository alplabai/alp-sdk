### Fixed — onnxruntime recipe no longer segfaults on first model load (abseil/protobuf ABI skew) (#2500)

`onnxruntime_1.28.0.bb` compiled ORT against a fetched abseil `20250814.0` but
linked the distro `libprotobuf-lite.so.25.8.0`, which was built against the
distro abseil `20240116`. The mismatched `absl` layouts crashed in
`RepeatedPtrFieldBase::MergeIntoClearedMessages` on the first ONNX model load.

The recipe now builds the protobuf that ORT's own `cmake/deps.txt` pins
(v21.12, which has no abseil dependency) as a private static library, and
`libonnxruntime.so` no longer NEEDs any distro `libprotobuf`. A new
`protobuf-ort-native` recipe supplies the matching host `protoc`; the distro
`protobuf` and `protobuf-native` are dropped from `DEPENDS`.
