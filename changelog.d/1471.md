### Removed — the host-side model engine moved to tan (ADR-0028)

`scripts/alp_model/` and `scripts/alp_cli/model.py` are deleted; the engine
now ships as `tan.model` in `alplabai/tan-cli`. `alp model build` is gone —
use `tan model build`. alp-sdk keeps every per-NPU fact the engine reads
(`metadata/npu_ops/`, `metadata/schemas/`, the `inference_arena_sram_kib`
budgets) and the on-device `.alpmodel` reader (`src/common/alp_model.c`),
which are unchanged.

No alp-sdk build path is affected: no CMake, Yocto recipe or example imported
the Python package. `examples/aen/aen-npu-inference-alp` drives its own
`gen_model.py`, which spawns `vela` directly.

**This deletion and tan-cli's relocation (`feat/model-engine-migration`) MUST
merge together.** Merging this alp-sdk change without tan's side leaves `tan
model build` with no engine and every model build fails for every user.

Test coverage moved with the code it exercised: `tests/scripts/test_alp_model_*.py`,
`test_alp_cli_model.py`, and the two real-model e2e proofs
(`test_deepx_yolo_internal.py`, `test_vela_yolo_internal.py` — a real
compiled yolo11n via `dxcom` and a real int8 detector via `vela`) are gone
from alp-sdk and now live under `tan-cli`'s `python/tests/model/`. Three
cross-cutting tests stayed and were re-expressed against alp-sdk's own
surface instead of the departing engine: `test_silicon_ref_single_source.py`
now pins the ValueError/FileNotFoundError distinction directly against
`resolve_soc_path()` rather than through `alp_model.targets.resolve_targets()`;
`test_alp_cli_new_som.py` and `test_resolve_generated_conflicts.py` drop
their `alp_model` entries.

The `model-io` `pyproject.toml` extra (tflite + flatbuffers, installed only
for the now-departed tensor-I/O tests) is gone. `model-compile`
(`ethos-u-vela` + tflite + flatbuffers) stays: `scripts/gen_npu_ops.py` still
needs a real `vela` to regenerate `metadata/npu_ops/ethos_u/*.json`, and
`tests/fixtures/models/gen_tiny_model.py` still needs it to rebuild
`tiny_int8.tflite`, the NPU fixture `examples/aen/aen-npu-inference{,-alif}`
compile for real silicon.

Regenerated `tests/fixtures/alpmodel/minimal.alpmodel`,
`tests/unit/alpmodel_reader/src/fixture.h` and `tests/yocto/onnx_cpu_fixture.h`
from `tan.model._gen_fixture` — byte-identical except the provenance banner
(`python -m alp_model._gen_fixture` → `python -m tan.model._gen_fixture`).
