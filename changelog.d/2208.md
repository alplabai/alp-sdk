### Fixed — M33 library routing no longer claims a nonexistent DRP-AI TFLM backend (#2208)

The `tflite-micro` Zephyr hardware-backend profile used the SoM-wide
`drp_ai` capability to emit `CONFIG_ALP_TFLM_DRP_AI=y` for V2N101 and V2M101
M33 slices.  No Zephyr/M-class DRP-AI backend exists, so the symbol was an
inert but false build claim.  The DRP-AI entry and its Zephyr-only Kconfig
symbol are removed, the affected emit fixtures now pin their absence, and
the M33 examples describe the backend set actually available to their slice.

The independent A55/Yocto backend remains unchanged: `PACKAGECONFIG[drpai]`
still enables `ALP_SDK_USE_DRPAI_V2N` and compiles the real Linux userspace
backend in `src/yocto/inference_drpai.cpp`.
